# Building the slide deck

The presentation is a [reveal.js](https://revealjs.com) deck. The **only file you
edit** is [`index.template.html`](index.template.html) (it references `figures/*.png`
and CDN assets, so it diffs cleanly). Two self-contained, shareable variants are
generated from it:

| file | layout |
|------|--------|
| `index.html`        | vertical section stacks (→ Parts, ↓ slides within a Part) |
| `index-linear.html` | flat, front-to-back linear reading |

Each built file inlines the local figures (base64) and the CDN assets (reveal.js,
theme, MathJax) into **one** file that opens offline — no `figures/` dir or network
needed to *view* it.

## Rebuild the deck (fast — after editing the template)

```bash
bash doc/slides/build.sh
```

This runs [`../../workflow/scripts/export_html.py`](../../workflow/scripts/export_html.py)
(Python **standard library only** — no packages to install) and writes both variants.
A **network connection is needed on the build machine** to fetch and inline the CDN
assets; without it the deck still builds but keeps CDN `<link>`/`<script>` tags (so it
then needs the internet to render). Open `doc/slides/index.html` in any browser.

Equivalently, directly:

```bash
python3 workflow/scripts/export_html.py doc/slides
```

## Regenerate the figures (slower — needs the simulations)

`figures/*.png` are produced from the study results, not by `build.sh`. They are
(re)generated by the Snakemake **`report`** rule of a study whose config sets
`export_slides: true`, which runs the solvers, aggregates the CSVs, and calls
`workflow/scripts/plots.py`. The deck-refreshing runs (see `../../README.md` and
`../../workflow/README.md`):

```bash
# from the repo root, in the OpenFOAM environment (see the repo README):
snakemake --configfile config/bulkVortexHighRes.yaml   --cores N   # extension figures (~46 min)
snakemake --configfile config/steadyVortex2DHighRes.yaml --cores N  # steady_* figures
snakemake --configfile config/bulkVortexSLHighRes.yaml  --cores N   # semi-Lagrangian sl_* figures
```

A few small figures are standalone: `sl_nested_vs_quad.png` and
`static_indicator_volume_convergence.png` regenerate from the helper scripts in
`workflow/scripts/` (`make_indicator_static_fig.py`, and the SL harnesses) — see the
headers of those scripts.

## Dependencies

- **View / rebuild HTML**: `python3` (≥ 3.8, standard library) + a browser. Network on
  first build to inline CDN assets.
- **Regenerate figures**: the Python analysis stack in
  [`../../requirements.txt`](../../requirements.txt)
  (`pip install -r requirements.txt` → matplotlib, numpy, foamlib) **plus**
  Snakemake and a built **OpenFOAM v2506** with the `leia` libraries/solvers compiled
  (the studies run the solvers). See `../../README.md` for the OpenFOAM build.
