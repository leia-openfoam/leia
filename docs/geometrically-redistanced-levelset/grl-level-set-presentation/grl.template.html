Geometric redistancing: planeFootWave

anchors from the indicator's own LLS planes · a donor-plane MeshWave fill · a criterion that keeps events rare

Measured dead ends and their repairs: companion deck grl-negative-results.

Idea: redistance to the interface the solver already sees

  • Advection degrades \(|\nabla\psi| = 1\); classic PDE reinitialization \(\partial_\tau\psi = \mathrm{sign}(\psi)(1-|\nabla\psi|)\) moves the interface while fixing the gradient (and worse — companion deck).
  • But the phase indicator ALREADY reconstructs, per band cell, a least-squares interface plane \(\psi^{\ell}_c(\mathbf{x}) = \mathbf{n}_c\cdot\mathbf{x} + d_c\) — the discrete interface.
  • Redistance to those planes. Exact signed distances near \(\Sigma\), a monotone geometric fill everywhere else — no PDE, no pseudo-time, no parameters.
  • Consistency by construction: \(\alpha\) (tet-fill of the planes) and the redistanced \(\psi\) (distances to the same planes) cannot disagree about where the interface is.
The whole method is one design decision applied twice: the LLS plane is the single source of interface geometry — the indicator integrates it, the redistancer measures distance to it.

The plane, normalized

Per band cell \(c\) (sign-change cells), fit over the cell + face neighbours \(S_c\) (one matched halo exchange in parallel):

\[ (\mathbf{n}_c, d_c) = \arg\min \sum_{k\in S_c} \big(\psi_k - (\mathbf{n}\cdot\mathbf{x}_k + d)\big)^2 \]

4×4 normal equations (2D: empty direction pinned); degenerate fits (\(|\mathbf{n}_c| \approx 0\)) are excluded.

Normalization is load-bearing: \(|\mathbf{n}_c|\) deviates from 1 by exactly the \(|\nabla\psi|\) drift being repaired. The Hesse-normal form

\[ \hat{\mathbf{n}}_c = \frac{\mathbf{n}_c}{|\mathbf{n}_c|}, \qquad \delta_c(\mathbf{x}) = \frac{\mathbf{n}_c\cdot\mathbf{x} + d_c}{|\mathbf{n}_c|} \]

makes \(\delta_c\) the EXACT signed distance to the plane's zero set.

Shared code path: leastSquaresPlaneCoeffs() (levelSetPlaneReconstruction.H) — the same call the detrixheAslam indicator makes.

Anchors: band + first ring

  • Band \(c\in B\): own plane, \(D_c = \delta_c(\mathbf{x}_c)\), foot \(\mathbf{f}_c = \mathbf{x}_c - D_c\hat{\mathbf{n}}_c\). Error: plane fit of a smooth interface, \(\mathcal{O}(h^2\kappa)\).
  • First ring \(r\): plicRDF-weighted donor evaluation \[ D_r = \frac{\sum_c w_{rc}\,\delta_c(\mathbf{x}_r)}{\sum_c w_{rc}},\ \ w_{rc} = \Big(\tfrac{\mathbf{f}_c-\mathbf{x}_r}{|\mathbf{f}_c-\mathbf{x}_r|}\cdot\hat{\mathbf{n}}_c\Big)^{2} \] (Scheufler & Roenby 2019).
  • One ring only: plane extrapolation degrades as \(\tfrac12|\mathbf{x}-\mathbf{f}|^2\kappa\), and anchors are hard constraints the fill cannot correct.

The donor-plane wave

  • Seeds: every face of every band cell carries \((\mathbf{f}_c, \hat{\mathbf{n}}_c, |\mathbf{x}_f-\mathbf{f}_c|^2)\); shared faces keep the closer donor.
  • MeshWave/FaceCellWave orders donors by foot distance (monotone, causal, \(\mathcal{O}(N)\), parallel-native); the received value is \[ \psi_{new} = \mathrm{sign}(\psi_{old})\,\big|(\mathbf{x}-\mathbf{f})\cdot\hat{\mathbf{n}}\big| \]
  • Then the exact anchor override on band + ring; unreached cells keep \(|\psi_{old}|\).
  • Payload matters: v1 carried only the foot — measured scalloping floor (companion deck).

The hot loop

// planeFootWaveRedistancer.C — seed the donor planes, wave, evaluate
forAll(anchors.bandCells, i)
{
    const point&  foot = anchors.bandFoot[i];
    const vector& nHat = anchors.bandNHat[i];
    for (const label faceI : mesh_.cells()[anchors.bandCells[i]])
    {
        const scalar dist2 = magSqr(Cf[faceI] - foot);          // ordering metric
        // ... per-face dedup: keep the smaller dist2 ...
        seedInfo.append(wallPointData<vector>(foot, nHat, dist2));
    }
}

MeshWave<wallPointData<vector>> wave(mesh_, seedFaces, seedInfo, nTotalCells+1);

forAll(psiIn, celli)                                            // donor-plane evaluation
{
    const scalar d = cellInfo[celli].valid(dummyTd)
      ? mag((C[celli] - cellInfo[celli].origin()) & cellInfo[celli].data())
      : mag(psiOld[celli]);                                     // unreached: keep old
    psiIn[celli] = (psiOld[celli] >= 0) ? d : -d;               // re-sign
}
forAll(anchors.cells, i) psiIn[anchors.cells[i]] = anchors.dist[i];  // exact anchors

No parameters, no linear solves, no pseudo-time. One matched halo exchange (plane fits) + the parallel-native wave.

Guarantees & measured properties

  • Planar interfaces: machine-exact over the whole trigger band (\(8\!\cdot\!10^{-14}\) @ \(N=64\)); 1D case globally exact (\(5\!\cdot\!10^{-15}\)).
  • Curved interfaces: second order in the band — static circle gate, band \(L_\infty(\psi-\psi_{exact})\): 4.1e-3 / 7.0e-4 / 1.8e-4 / 4.5e-5 @ \(N=32/64/128/256\).
  • Events improve the field: band mean \(||\nabla\psi|-1|\) 0.537 → 5.1e-3 in one event (@ \(N=64\)) — the pass criterion every fill must meet.
  • Monotone (wave distances only shrink), sign-preserving outside the band (no bulk topology change); band cells may realign sub-\(h\) — the solver refreshes band + \(\alpha\) and logs the volume shift per event.
  • Trigger: fires only when band \(L_1(||\nabla\psi|-1|) > (h/L)^2\) (Abu-Al-Saud et al. 2018) — redistancing stays rare.

Part 4 of 6

Verification

the two static gates decide; the advected studies measure what compounds

Does one redistancing step move the interface?

Input = exact signed distance (circle \(R=0.15\) centered; diagonal plane). Redistancing it must leave the interface position, the phase volume and the signed-distance profile unchanged — every deviation is the interface displacement of ONE redistancing step (the classical reinitialization concern, Sussman et al. / Russo–Smereka).

  • planeFootWave: planar interface preserved to machine precision (1e-14, volume change ~1e-16); circle = spurious volume change PER REDISTANCING STEP \(= \mathcal{O}(h^2)\): 1.05e-4 → 1.72e-6 @ N=32→256 (1.5% → 0.02% of the phase volume).
  • Shape error \(=\) volume error EXACTLY at every N: the interface displacement is one-signed — the least-squares chord-plane bias, not noise. anchoredEikonal: identical volume change (interface position is set by the anchors, not by the far-field distance propagation).

What the advected studies measured (so far)

  • noRedistancing converges cleanly (2D reversed vortex, shape 7.8e-5 → 8.2e-7) — until conditioning fails: at T=8, N=32/64 the interface VANISHES (volume error = 1, empty band).
  • Band-mean trigger criterion: degenerates to every-step firing (ablation: identical to 3 digits; thresholds 0.01/0.05 change nothing) — every-step × per-event \(\mathcal{O}(h^2)\) displacement = volume runaway (companion deck).
  • Consequence (the design under way): trigger on the conditioning extremes only — band \(\min|\nabla\psi| \to 0\) (flattening/interface loss) or \(\max|\nabla\psi|\) large (quasi-Dirac) — so the event budget stays \(\ll\) steps and the total volume cost stays events × \(\mathcal{O}(h^2)\).
