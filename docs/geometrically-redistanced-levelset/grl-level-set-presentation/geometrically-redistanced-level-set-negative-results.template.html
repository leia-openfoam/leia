Part 1 of 6

The gate

the method in one slide · the static gate that decides · the governing lesson

The method in one slide

  • Advect \(\psi\) as a PDE with the plain prescribed flux: \(\partial_t\psi + \nabla\cdot(\mathbf{v}\psi) - \psi\,\nabla\cdot\mathbf{v} = 0\) (advective form; optional Helmholtz projection -fluxCorrection).
  • Restore the signed-distance property geometrically, from the same linear least-squares interface planes the Detrixhe–Aslam phase indicator already reconstructs per cell.
  • Anchors (exact, hard): band cells — own normalized plane; first ring — plicRDF-weighted donor-plane distances.
  • Fill (the rest of the domain) — the sweepable model: planeFootWave (MeshWave), anchoredEikonal (steady solve), PDE (Sussman baseline).
  • Events fire through a criterion (gradPsiThreshold: band \(L_1(\,||\nabla\psi|-1|\,) > (h/L)^2\)) — redistancing is rare, not per-step.

Consistency by construction: the indicator and the redistancer read the SAME planes — \(\alpha\) and \(\psi\) cannot disagree about where the interface is.

The static gate

  • Case cases/2DredistanceCircle: circle \(R=0.25\) in the unit square, \(\psi_0 = \ell\,\tanh\!\big(d/(\ell\,\varepsilon)\big)\), \(\ell=0.1\), \(\varepsilon=0.5\): exact zero set, \(|\nabla\psi|(\Sigma)=2\), saturates to \(\pm0.1\) — deliberately hostile.
  • leiaTestRedistance applies one event and measures against the analytic SDF \(|\mathbf{x}-\mathbf{c}|-R\) over the trigger band \(B=\{|\psi_{exact}|\le 6h\}\) — the region the indicator and the criterion read.
  • Pre-event @ \(N=64\): band \(L_\infty(\psi)\) = 2.66e-2, band mean \(||\nabla\psi|-1|\) = 0.537.
pass criterion post-event band error \(\le\) pre-event band error,
interface metrics unchanged.
An event that fires must improve the field it was called to repair.

Reproducible: snakemake --workflow-profile profiles/local --configfile config/redistanceCircle2D.yaml

The gate is static on purpose: no advection error mixed in, an analytic reference, and one event. If a fill cannot pass here it cannot help anywhere.

The governing lesson

measured, both v1 fills A redistance event raised the band deviation it exists to lower:
band \(L_1(||\nabla\psi|-1|)\): 6.9e-3 → 8.6e-2 (Eikonal), → 2.1e-2 (foot wave, 76-seed cloud).
  • Consequence: no trigger policy can help. If firing injures, the only "good" schedule is never — the criterion literature (Abu-Al-Saud et al. 2018) presumes a fill worth calling.
  • Fill quality is upstream of every trigger/threshold study; the static gate therefore gates all of them.
This reframed the work: before studying WHEN to redistance, make the event itself non-injuring. Both repairs below are measured against the gate.

Part 2 of 6

Foot-cloud scalloping

planeFootWave v1: distance to discrete foot points

What we tried (v1)

  • Each band cell's LLS plane contributes its foot point \(\mathbf{f}_c = \mathbf{x}_c - d_c\,\hat{\mathbf{n}}_c\) as a MeshWave<wallPointData<scalar>> seed.
  • Every cell receives the Euclidean distance to its nearest foot point: \(\;\psi_{new} = \mathrm{sign}(\psi_{old})\,\min_i |\mathbf{x}-\mathbf{f}_i|\).
  • Band + ring anchors overridden with exact plane distances; monotone, causal, parallel-native, no parameters.
measured verdict — injures Event gate: band \(L_1(||\nabla\psi|-1|)\) 6.9e-3 → 2.1e-2.
Static gate @ \(N=64\): band \(L_\infty(\psi)\) = 6.1e-3, band \(L_\infty(||\nabla\psi|-1|)\) = 0.167.

Why: the scalloping mechanism

  • \(\min_i|\mathbf{x}-\mathbf{f}_i|\) is a union of cones: its level sets bulge between feet (sagitta \(\approx s^2/8d\), \(s\) = foot spacing).
  • \(\psi\) error is small — but \(\nabla\psi\) kinks at every donor boundary, and the band deviation the trigger reads is exactly a gradient norm: the scalloping lands on the quantity being policed.
  • A resolution-independent floor: refining moves the feet closer but the kink pattern persists at the new scale.

The repair: evaluate the donor PLANE, not its foot

  • Payload upgrade: wallPointData<vector>(foot, nHat, distSqr) — the wave still orders donors by foot distance, but the received value is the continuous donor-plane evaluation \(\;\psi_{new} = \mathrm{sign}(\psi_{old})\,\big|(\mathbf{x}-\mathbf{f})\cdot\hat{\mathbf{n}}\big|\) — geometricVoF/plicRDF's trick.
  • Moving parallel to the plane no longer changes the value: the scalloping is removed structurally, not tuned away.
measured verdict — pass Static gate, post-event band \(L_\infty(\psi-\psi_{exact})\): 4.1e-3 / 7.0e-4 / 1.8e-4 @ \(N=32/64/128\) — second order (was 6.1e-3 @ 64: 8.7×).
Band mean \(||\nabla\psi|-1|\): 0.537 → 5.1e-3 @ \(N=64\).
Planar field: machine-exact over the whole \(6h\) band (\(L_\infty=8\!\cdot\!10^{-14}\)); 1D case globally exact.

planeFootWave is the working model.

The ordering metric stays the foot distance (guarantees monotone causal propagation); only the VALUE changed to the plane evaluation. On a single plane every donor evaluates to the same infinite plane, hence machine exactness in the planar unit test.

Part 3 of 6

The Eikonal fill

anchoredEikonal: plateau fixed — the first-order fill remains

What we tried

  • Tucker-regularized steady Eikonal for the unsigned distance \(y\): \(\;\nabla\cdot(\hat{\mathbf{n}}y) - y\nabla\cdot\hat{\mathbf{n}} - \epsilon\, y\,\nabla^2 y = 1\), direction frozen per iteration (OpenFOAM's advectionDiffusion wall-distance discretization, with fvMatrix::setValues internal Dirichlet anchors).
  • Defaults inherited from OpenFOAM: \(\epsilon=0.1\), tolerance 1e-3, maxIter 10.
measured verdict v1 — injures Event gate: band \(L_1(||\nabla\psi|-1|)\) 6.9e-3 → 8.6e-2.
Diagnosis: the frozen-direction iteration hit maxIter=10 with the residual plateaued at ~1e-3 — the fill returned un-converged.

Repair attempt: iteration budget

  • maxIter 100, tolerance 1e-4 (set in the case dictionaries, never hardcoded).
  • Result: converges in 4 outer iterations (final residual 4.8e-5) — the plateau was purely budget. The event now improves the field: band mean \(||\nabla\psi|-1|\) 0.537 → 4.3e-2 @ \(N=64\).
measured verdict v2 — converged, still loses ~8× worse than the wave at every resolution (band \(L_\infty(\psi)\): 3.0e-2 / 5.8e-3 / 1.4e-3 vs 4.1e-3 / 7.0e-4 / 1.8e-4).
Planar unit test: the fill is first order inside the trigger band — \(6h\)-band \(L_\infty(\psi)\) = 2.6e-2 / 1.5e-2 / 7.6e-3 @ \(N=32/64/128\) (\(\approx 0.8\!-\!1.0\,h\)) on an EXACT planar field.

Why, and the documented status

  • Mechanism: the fill transports distance with first-order upwind (\(O(h)\)) plus the \(\epsilon\,y\,\nabla^2 y\) regularization bias — both contaminate the outer band cells that the trigger criterion and the indicator read; the anchors (band + ring) stay machine-exact.
  • The obvious cure is a documented divergence: the second-order deferred-corrected linearUpwind on a STEADY transport equation (no \(\partial_t\) damping) already diverged in the velocity-extension line (steadyUpwindLinear, "the Aslam cascade") — same equation class, same failure mode expected.
status anchoredEikonal stays in the code and in the study axis as the documented comparison model; the planar unit test records it as an expected fail of the \(6h\)-band bound. The wave is the working model.
Not deleted: a converged, honest second place is exactly what a comparison table needs, and its RTS model costs nothing to keep. But no further tuning effort goes here.

Part 4 of 6

PDE reinitialization

PDE (Sussman) baseline: two distinct failures

Failure 1: fixed \(\Delta\tau\) is a mesh-dependent time bomb

  • \(\partial_\tau\psi = \mathrm{sign}(\psi)\,(1-|\nabla\psi|)\): pseudo-time transport at unit characteristic speed — explicit Euler is CFL-limited by the mesh.
  • Historic settings \(\Delta\tau=0.1\), 10 iterations were tuned on the 1D case (\(h=1\)); on the circle gate at \(h=1/64\) the pseudo-CFL is ≈ 12.8.
measured verdict — blow-up Static gate @ \(N=64\): band \(L_\infty(\psi)\) 2.7e-2 → 7.5e+6.
repair deltaTCoeff: \(\Delta\tau = 0.5\,h_{min}\) (mesh-relative, backward compatible: deltaTCoeff ≤ 0 keeps the legacy fixed \(\Delta\tau\)); 30 iterations cover \(15h \supset\) the \(6h\) trigger band. No more blow-up at any \(N\).

Failure 2: stable, and still injures

measured verdict — injures at every N With \(\Delta\tau=0.5h\), 30 iterations, static gate: band mean \(||\nabla\psi|-1|\) 0.537 → 1.28 (\(L_\infty\!=\!6.8\)) @ \(N=64\); band \(L_\infty(\psi)\) = 0.37 / 0.17 / 0.089 @ \(N=32/64/128\) — first order, huge constants.
  • Mechanism: the implementation discretizes \(|\nabla\psi|\) with a central gradient (fvc::grad) — no Godunov upwinding. On the saturated tanh profile (plateaus \(|\nabla\psi|\to 0\), kinks where the reinitialized region meets the plateau) the central Hamiltonian oscillates; classic cures are Godunov flux + the Sussman–Fatemi / Russo–Smereka subcell fixes — a research line of its own.
  • The 1D redistance case passed for years because \(h=1\) and the profile was globally linear: the historical config masked both failures.
  • The geometric route sidesteps this entirely: no pseudo-time PDE, no Hamiltonian discretization, no interface displacement.
status Kept as the classic baseline in the advection studies (near-SDF regime is milder than the saturated gate); the static verdict stands in the comparison table.

Part 5 of 6

Measurement pitfalls

two "failures" that were bugs in the measuring stick, one inflated constant

Wrong reference: infinite plane vs interface patch

  • The planar unit test first asserted the global field against the infinite plane's distance — and "failed" at \(1.7h\) near domain corners.
  • But the interface only exists inside the domain: beyond the ends of its trace, the distance to the interface patch legitimately exceeds the infinite-plane distance. The model was right; the reference was wrong.
  • Same lesson for boundary-cell gradients: noBvGrad deliberately ignores patch values, so a PERFECT plane "fails" a global gradient check at boundary cells (measured: 0.57).
repair Assertions now match each model's contract region: machine exactness on the anchor set (band + ring), sanity bounds over the \(6h\) trigger band, interior cells only for gradient checks; the far field is reported, never asserted.

Inflated constants: the saturated tanh

  • The gate's initial profile \(0.1\tanh(d/0.05)\) is stencil-nonlinear at coarse \(N\): the LLS plane fit absorbs profile curvature and geometry error, inflating the static band constants (e.g. 4.1e-3 @ \(N=32\) vs the pure \(h^2\kappa/2 \approx 2\!\cdot\!10^{-3}\)).
  • Kept deliberately: an advected \(\psi\) between redistance events looks exactly like this — a gate on pristine SDF input would flatter every model. The convergence ORDER (2.5 → 2.0 across \(32/64/128\)) confirms the nonlinearity washes out under refinement.
Not repaired on purpose — documented so nobody "fixes" the gate into an easier test and celebrates the smaller constants.

Standing rules distilled from the dead ends

  • 1. An event must not injure. The static gate (post \(\le\) pre on the band) gates every fill change — before any trigger, threshold, or advection study spends compute.
  • 2. Trigger policy is downstream of fill quality. No schedule rescues a harmful fill; tune criteria only for fills that pass rule 1.
  • 3. Assert each model's contract region. Anchors: machine exact. Trigger band: bounded. Far field: reported, not asserted. A test that asserts outside the contract manufactures false negatives.
  • 4. Mesh-relative parameters only. Any dimensional constant tuned on one mesh (\(\Delta\tau=0.1\)) is a latent divergence on the next one.
  • 5. Distances come from continuous geometry. Evaluate planes, not point clouds — discrete minima put kinks into exactly the gradient norms the method polices.
