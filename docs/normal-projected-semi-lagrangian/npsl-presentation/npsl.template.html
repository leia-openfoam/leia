Normal-projected semi-Lagrangian level set (nSL)

geometric transport along \((\mathbf u\cdot\mathbf n)\,\mathbf n\) with per-step renormalization of the distance property

Why: two measured defects of the value path

  • Grid-scale corrugation. On an exact rigid translation (\(\sigma=0\), free stream preserved to \(3\times10^{-15}\) m/s) the \(\psi=0\) contour grows a \(\lambda\approx 2h\) corrugation at 0.19–0.28 per cell of displacement, nearly independent of Co over \([0.007, 0.5]\) — a property of the per-step reconstruct-and-evaluate resampling.
  • \(|\nabla\psi|\) collapse orders every coupled failure. Across a 10-run droplet matrix, band \(\min|\nabla\psi|\) ranks all outcomes and its collapse precedes the parasitic-current growth by ~8 ms.

nSL removes the value resampling entirely and renormalizes the band every step — locally, zero-set-preservingly, without redistancing (measured to rebuild distance to advection noise).

The tangential velocity is exactly redundant

\[ \mathbf u = v_n\mathbf n + \mathbf u_t,\qquad \mathbf n = \frac{\nabla\psi}{|\nabla\psi|},\qquad \mathbf u_t\cdot\nabla\psi \equiv 0 \] \[ \Rightarrow\quad \frac{\partial\psi}{\partial t} + \mathbf u_n\cdot\nabla\psi = 0, \qquad \mathbf u_n = (\mathbf u\cdot\mathbf n)\,\mathbf n \]
  • \(\psi\) is constant along trajectories of \(\mathbf u_n\) — for any field, drifted or not
  • pure tangential motion is an exact no-op: \(\mathbf u_n = 0 \Rightarrow \mathbf x_d = \mathbf x_c\)
  • the normal comes from the quadratic fit: \(\mathbf n = \mathbf g/|\mathbf g|\), \(\mathbf g = \nabla R_c(\mathbf x_c)\) — never from an FVM gradient of \(\psi\)

The discrete trace — departure-centred, AB2

the coupled solver advects before its momentum solve: only \(\mathbf u^{n}\) and the stored projection \(\mathbf u_n^{\,n-1}\) exist (previous step's normals — never re-projected)

\[ \mathbf x_d = \mathbf x_c - \Delta t\left[\mathbf u_n^{\,n} + \tfrac{r}{2}\left(\mathbf u_n^{\,n}-\mathbf u_n^{\,n-1}\right)\right] + \tfrac{\Delta t^2}{2}\,(\mathbf u_n^{\,n}\cdot\nabla)\,\mathbf u_n^{\,n}, \quad r = \tfrac{\Delta t}{\Delta t_0} \]

\(\nabla\mathbf u_n\) assembled analytically — never by differencing the projected field (OpenFOAM convention \((\nabla u)_{ij}=\partial_i u_j\)):

\[ \partial_i n_j = \frac{H_{ij} - (\mathbf H\mathbf n)_i n_j}{|\mathbf g|},\quad \nabla v_n = \nabla\mathbf u\cdot\mathbf n + \nabla\mathbf n\cdot\mathbf u,\quad \nabla\mathbf u_n = \nabla v_n\otimes\mathbf n + v_n\nabla\mathbf n \]

\(|\mathbf u_n|\le|\mathbf u|\): the nSL trace is never longer than the baseline trace; same stencil guard.

The geometric update

\(\;\psi^{n+1}(\mathbf x_c) = d_c + \delta,\qquad \delta = (\mathbf x_d - \mathbf x_c)\cdot\mathbf n\;\)

  • \(d_c\): signed offset of \(\mathbf x_c\) from the cell's own model zero set — never interpolates \(\psi\) at \(\mathbf x_d\)
  • exactly zero-preserving: \(\psi_c = 0 \Rightarrow d_c = 0\) — renormalization never moves the front
  • clean SDF + uniform \(v_n\): \(d_c + \delta = \psi_c - v_n\Delta t\) exactly

Offset engine (b), stable quadratic root (ray-restricted model \(R(s)=\psi_c + s|\mathbf g| + \tfrac12 s^2 h_{nn}\)):

\[ d_c = \frac{2\psi_c}{|\mathbf g| + \sqrt{D}},\qquad D = |\mathbf g|^2 - 2\psi_c h_{nn},\qquad \text{accept iff } D \ge \beta|\mathbf g|^2 \]

first-order fallback \(\psi_c/|\mathbf g|\) otherwise; the same conversion serves the curvature path (offsetCorrection quadraticRoot) — transport and curvature never disagree about a cell's offset.

Offset engine (a): the stabilized foot-point

both legs curvature-aware, on the local model: \(d_c\) = distance of \(\mathbf x_c\) to \(\{R_c=0\}\); displacement = distance of \(\mathbf x_d\) to the cell's own iso-surface \(\{R_c=\psi_c\}\)

  • alternate tangent-plane projection and Newton surfacepoint pulls; the two step vectors \(\mathbf f_1, \mathbf f_2\) of each cycle define a parabola — an empirical curvature sample at first-derivative cost
  • one Newton step on the distance-minimizing cubic: \(\alpha = 1 - \frac{a_0+a_1+a_2+a_3}{a_1+2a_2+3a_3}\), guarded \(0<\alpha<\alpha_{\max}\)
  • pure polynomial arithmetic in the fit coefficients; foot must stay inside the stencil trust region; per-cell fallback to the ray root (counted)

full algorithm + failure modes: stable-foot-point-3d.md
