The level set

Signed-distance field \(\psi(\mathbf{x},t)\):

\[ \Sigma = \{\mathbf{x} : \psi = 0\}, \quad \Omega^{-}=\{\psi<0\} \;(\text{phase A}) \]

Signed-distance property

\[ |\nabla\psi| = 1 \]

Distance to \(\Sigma\); sign encodes the phase.

Everything downstream assumes psi is a signed distance. When advection erodes that property, the phase indicator and surface tension degrade — which motivates redistancing and (crucially) velocity extension later in the talk.

Advection

Conservative transport of the level set:

\[ \frac{\partial \psi}{\partial t} + \nabla\!\cdot(\mathbf{u}\,\psi) = S \]

discretised with the finite-volume flux \(\phi = (\mathbf{u}_f\cdot\mathbf{S}_f)\):

fvm::ddt(psi) + fvm::div(velExt->phi(), psi) == source->fvmsdplsSource(psi, U)
The solver is deliberately thin: it wires up autoPtr-held models and runs a fixed pipeline each step. Note the equation advects with velExt->phi(), not the raw phi — that is the non-invasive coupling point for velocity extension.

Phase indicator / Heaviside

Volume fraction of phase A in cell \(c\):

\[ \alpha_c = \frac{1}{|\Omega_c|}\int_{\Omega_c} H(-\psi)\,\mathrm{d}V, \qquad H(s)=\begin{cases}1 & s>0\\ 0 & s\le 0\end{cases} \]

Problem: an algebraic Heaviside of the transported \(\psi\)

  • is only first order at the interface, and
  • relies on \(\psi\) staying a signed distance (\(|\nabla\psi|=1\)).

Both assumptions are violated by advection.

The naive indicator (heavisidePhaseIndicator / sharpJump) just thresholds psi. Cheap, but its accuracy is capped and it drifts as |grad psi| leaves 1. We want an indicator whose order follows psi and does not depend on the SDF property.

Idea: recover \(\alpha\) geometrically

Per cell, build a linear reconstruction of \(\psi\):

\[ \psi^{\ell}_c(\mathbf{x}) = \mathbf{n}_c\cdot\mathbf{x} + d_c \]

then compute \(\alpha_c\) as the fraction of the cell below that plane.

  • \(\alpha\) inherits the order of \(\psi\)
  • no \(|\nabla\psi|=1\) requirement
This is the shared design principle behind both geometric indicators: the reconstruction (plane) is computed the same way; only the "clip the cell" step differs (polygon intersection vs analytic tet fill).

LLS reconstruction

Shared code: levelSetPlaneReconstruction

Fit the plane over cell \(c\) and its neighbours \(N_c\) by least squares:

\[ \min_{\mathbf{n}_c,\,d_c}\; \sum_{k\in\{c\}\cup N_c}\big(\psi_k-(\mathbf{n}_c\cdot\mathbf{x}_k+d_c)\big)^2 \]

Normal equations — a \(4\times4\) system for \((n_x,n_y,n_z,d_c)\):

\[ \left[\begin{array}{cccc} \sum x_k^2 & \sum x_k y_k & \sum x_k z_k & \sum x_k \\ \sum x_k y_k & \sum y_k^2 & \sum y_k z_k & \sum y_k \\ \sum x_k z_k & \sum y_k z_k & \sum z_k^2 & \sum z_k \\ \sum x_k & \sum y_k & \sum z_k & N \end{array}\right] \!\begin{bmatrix} n_x\\ n_y\\ n_z\\ d_c \end{bmatrix} =\begin{bmatrix} \sum \psi_k x_k\\ \sum \psi_k y_k\\ \sum \psi_k z_k\\ \sum \psi_k \end{bmatrix} \]

2D fix: in an empty direction, row/col is decoupled and \(n_{\text{cmpt}}\!=\!0\) is pinned → keeps the \(4\times4\) system non-singular (mesh.geometricD()).

Solved with simpleMatrix (small direct solve). Coupled-boundary neighbours are added explicitly for parallel correctness. In 1-cell-thick 2D/1D meshes there is no variation along the empty direction, so that normal component is undetermined and the matrix is singular; pinning it to 0 and decoupling the row/column fixes it.

Geometric Heaviside

geometricPhaseIndicator — clip the cell against the plane

\[ \alpha_c = \frac{\big|\{\mathbf{x}\in\Omega_c : \psi^{\ell}_c(\mathbf{x})<0\}\big|}{|\Omega_c|} \]

The below-plane sub-volume is found by polygon/polyhedron intersection (divergence-theorem volume of the clipped cell).

intersectCell + hesseNormalPlane do the clipping; the negative volume is clamped and divided by the cell volume. Accurate, but the polygon intersection carries geometric tolerances and edge cases (plane grazing a face).

Analytic volume fraction — Detrixhe & Aslam (2016)

Decompose the cell into tets (cell centroid \(\mathbf{x}_c\), face centroid \(\mathbf{x}_f\), face-edge vertices):

Sort vertex distances \(\psi_1\!\le\!\psi_2\!\le\!\psi_3\!\le\!\psi_4\). Fraction of the tet in \(\Omega^{-}\):

\[ f = \begin{cases} 1 & \psi_4 \le 0\\[2pt] 1 - \dfrac{\psi_4^{3}}{(\psi_4-\psi_1)(\psi_4-\psi_2)(\psi_4-\psi_3)} & \psi_3\le 0<\psi_4\\[10pt] \dfrac{\psi_3\psi_4(\psi_1^2+\psi_1\psi_2+\psi_2^2) - \psi_1\psi_2(\psi_1+\psi_2)(\psi_3+\psi_4) + \psi_1^2\psi_2^2} {(\psi_3-\psi_1)(\psi_4-\psi_1)(\psi_3-\psi_2)(\psi_4-\psi_2)} & \psi_2\le 0<\psi_3\\[10pt] -\dfrac{\psi_1^{3}}{(\psi_2-\psi_1)(\psi_3-\psi_1)(\psi_4-\psi_1)} & \psi_1\le 0<\psi_2\\[6pt] 0 & \psi_1>0 \end{cases} \]
Sort the four vertex distances and apply the closed form; f is the fraction of the tet in Omega^-. The cell value is assembled on the next slide.

Analytic volume fraction — properties

Assemble the cell value as the tet-volume-weighted mean:

\[ \alpha_c = \frac{\sum_t f_t\,V_t}{\sum_t V_t} \]

Tolerance-free: the denominators are cross-interface distance gaps, bounded away from zero, so there is no clipping tolerance — it matches the polygon clipping to machine precision on the same plane, and stays robust in 2D.

The middle (two-in / two-out) case uses the corrected \(\Omega^{-}\) form — the paper's printed numerator gives the complement.

Denominators are products of cross-interface distance gaps, so they are bounded away from zero — no clipping tolerance. stabilise() only guards a vertex exactly on the interface. The middle-case numerator in the code is the corrected Omega^- form (verified vs divided-difference formula and direct integration).

Velocity extension — why

Only motion along the interface normal moves \(\Sigma\). The cell-centred \(\mathbf{U}\) varies along \(\mathbf{n}\), so advecting \(\psi\) with it changes the spacing of the level sets and breaks \(|\nabla\psi|=1\). The extension velocity \(\mathbf{U}_{\text{ext}}\) removes that variation, \((\mathbf{n}\cdot\nabla)\,\mathbf{U}_{\text{ext}}=0\), so each normal ray is advected rigidly.

Only the normal velocity component moves the interface; the tangential part just shears the level-set field and ruins the SDF property. Raw U varies along n, so the iso-psi contours change spacing (|grad psi| != 1); U_ext is constant along each normal, so the contours shift rigidly and |grad psi| = 1 is preserved.

Interface velocity

\(\mathbf{x}_\Sigma\) is the closest point on \(\Sigma\) to the cell centre — the orthogonal projection:

\[ \mathbf{x}_\Sigma=\operatorname*{arg\,min}_{\mathbf{y}\in\Sigma}\|\mathbf{x}_c-\mathbf{y}\| \]

Approximate it by steepest descent on \(\psi\) (\(\mathbf{n}=\nabla\psi/|\nabla\psi|\)):

\[ \mathbf{x} \leftarrow \mathbf{x} - \psi(\mathbf{x})\,\mathbf{n} \]

Exact in one step only for a true signed distance; otherwise the iterate \(\tilde{\mathbf{x}}\) lands near \(\mathbf{x}_\Sigma\) with an approximation error.

Then \(\mathbf{U}_\Sigma=\operatorname{interp}(\mathbf{U},\tilde{\mathbf{x}})\) — IDW cell-point interpolation.

interfaceExtension: seed cells = the single layer with \(0<\alpha<1\).

x_Sigma is the orthogonal projection (closest point) onto Sigma. Steepest descent on psi (n = grad psi / |grad psi|) approximates it: one step is exact only for a true SDF (|grad psi| = 1); otherwise the landing point x-tilde is displaced along Sigma -- an approximation error. interpolationCellPoint (inverse-distance from cell points) then samples U at x-tilde. Seed layer = interface-cut cells (fractional alpha).

Non-invasive coupling

  • Reads base \(\mathbf{U}\) and flux \(\phi\) (never mutated).
  • Writes a separate field \(\mathbf{U}_{\text{ext}}\) (AUTO_WRITE) and advection flux \(\phi_{\text{ext}}\).
  • \(\phi_{\text{ext}}\) is seamless: \(\mathbf{U}_{\text{ext}}\) fades into \(\mathbf{U}\) by a \(C^1\) cosine ramp over \(|\psi|\in[L,2L]\), \(L=\)nLayers\(\cdot h\) — a hard band-edge flux switch is a velocity discontinuity that writes irreversible \(|\nabla\psi|\) kinks.
  • Level-set equation advects with \(\phi_{\text{ext}}\) in advective form (no Helmholtz projection: it would destroy \((\mathbf{n}\cdot\nabla)\mathbf{U}_{\text{ext}}=0\)).
  • Default model none = identity (\(\mathbf{U}_{\text{ext}}\!=\!\mathbf{U}\)).
Clean separation of concerns: a future Navier-Stokes solve can own U/phi; velocity extension is an opt-in correction layer, so nothing breaks when it is "none". phi_ext = interpolate(Uext) & Sf on ALL internal faces (whole-domain, seamless); Uext itself is cosine-faded into U outside the band, so the flux has no discontinuity anywhere. Measured: a hard band-face switch grew the band L2 of ||grad psi|-1| ~10x (T=2, N=128) because the seam kinks return onto Sigma under flow reversal.

Velocity extension — the framework: the algorithm

  1. \(\hat{\mathbf n}=\nabla\psi/|\nabla\psi|\).
  2. band \(=\{\,|\psi|\le(n_{\text{layers}}{+}1)h\,\}\) plus seed cells \((0<\alpha<1)\).
  3. seed velocity: foot-point descent to \(\Sigma\), then cell-point interpolate \(\mathbf U\).
  4. model-specific extend() fills the band.
  5. clip \(|\mathbf U_{\text{ext}}|\le\texttt{maxScale}\cdot\max|\mathbf U|\).
  6. \(\phi_{\text{ext}}=\texttt{interpolate}(\mathbf U_{\text{ext}})\!\cdot\!\mathbf S_f\).
  7. \(C^1\) cosine fade \(\mathbf U_{\text{ext}}\!\to\!\mathbf U\) over \([L,2L]\).
  8. advect \(\psi\) with the advective equation (previous slide).

The \(-\psi\,\nabla\!\cdot\phi_{\text{ext}}\) term is fvm::Sp(divPhiExt, psi) — advective (non-conservative) \(\psi\)-transport. velocityExtension.

The framework decouples the extension into replaceable pieces: a normal, a narrow band, a seeding step, a model-specific extend, a clip, and a C1 cosine fade. The advective psi-eq uses the non-conservative -psi div(phi_ext) = fvm::Sp(divPhiExt,psi).

Model none — motivation: the control

Every extension model replaces the advecting flux with an approximation. Before trusting any of them, measure the control: what does doing nothing buy — and what does it cost?

  • Buys: \(\psi\) advected with the exact prescribed flux \(\phi\), discretely (near-)divergence-free ⇒ stable, conservative — the best transport a prescribed field admits.
  • Costs: \((\hat{\mathbf{n}}\cdot\nabla)\mathbf{U}\neq0\): level-set spacing distorts, \(|\nabla\psi|\) drifts like \(e^{\int\!\text{strain}\,dt}\).
  • Also the harness validator: its error ratio must be exactly 1 by definition.
Every measured claim about the extensions is a claim relative to this model. none is also the identity element of the design: the solver pipeline is unchanged, the extension stage merely re-syncs the registry fields. The costs bullet is the whole reason velocity extension exists (Part 2 opening slide).

none — model & discretization

The identity correction — no extension field is constructed:

\[ \mathbf{U}_{\text{ext}} = \mathbf{U}, \qquad \phi_{\text{ext}} = \phi \]
  • No linear system. correct() re-syncs the registry fields each step (after the oscillation rescaling of \(\mathbf{U}\), \(\phi\)): Uext == U; phiExt == phi;
  • The \(\psi\)-equation advects with velExt->phi() — here the exact prescribed flux. \(\nabla\!\cdot\!\phi\approx0\) discretely ⇒ the compression term \(-\texttt{fvm::Sp}(\nabla\!\cdot\!\phi,\psi)\) vanishes (verified: identical to machine precision).
  • Guaranteed extension property: none. \((\hat{\mathbf{n}}\cdot\nabla)\mathbf{U}_{\text{ext}} =(\hat{\mathbf{n}}\cdot\nabla)\mathbf{U}\) — the static ratio is \(\equiv 1\), which is exactly what makes it the reference.

Source — the base class itself, registered as type none: src/leiaLevelSet/velocityExtension/velocityExtension.C → velocityExtension::correct().

Design detail worth telling numericists: phiExt is NAMED "phi" but unregistered, so fvm::div(phiExt, psi) picks up the existing div(phi,psi) scheme from fvSchemes without clashing with the registered phi. That trick is reused by the Aslam cascade later.

none — code (the \(\psi\) advection all models feed)

// non-invasive: U/phi are never mutated; advect psi with velExt->phi().
// For "none", correct() simply re-syncs:  Uext == U;  phiExt == phi;
velExt->correct();

// The level set obeys the ADVECTIVE law Dpsi/Dt = 0, not a conservation law:
// a normal-constant extension velocity is generically NOT solenoidal
// (div(v0*n) = v0*kappa), so assemble (v.grad)psi exactly:
//   (v.grad)psi = div(phiExt psi) - psi (div phiExt).
const volScalarField divPhiExt("divPhiExt", fvc::div(velExt->phi()));

// Defect-correction loop: each pass re-assembles with the LATEST psi so the
// deferred (linearUpwind - upwind) correction converges (~2-3 passes -> 2nd
// order). Safe: fvm::ddt reuses psi.oldTime(), fixed within the step.
const label nDefCorr =
    runTime.controlDict().getOrDefault<label>("nDefCorr", 2);

for (label corr = 0; corr < nDefCorr; ++corr)
{
    fvScalarMatrix psiEqn
    (
        fvm::ddt(psi)
      + fvm::div(velExt->phi(), psi)     // Gauss linearUpwind grad(psi)
      - fvm::Sp(divPhiExt, psi)          // advective (non-conservative) form
     ==
        source->fvmsdplsSource(psi, U)
    );

    psiEqn.solve();
}

applications/solvers/leiaLevelSetFoam/leiaLevelSetFoam.C. grad(psi) = cellLimited leastSquares 1; div(phi,psi) = Gauss linearUpwind grad(psi). For none, \(\nabla\!\cdot\!\phi\approx0\) ⇒ the Sp term vanishes (verified: results identical to machine precision).

none — measured verdict

  • Static: ratio \(\equiv1\) — validates the harness exactly.
  • Reversed vortex (\(T{=}2\), \(N{=}256\); band grad / volume): 0.070 / 2\(\times\)10-4 — the best final-time numbers of all seven models.
  • But the benchmark flatters it: band \(L_2\) = 1.67 at \(t=T/2\) vs 0.0013 at \(t=T\) — a \(\sim\)1300× reversibility cancellation. At maximal deformation none is the worst model at every \(T\le4\); the extensions hold the band 6–15× tighter.
  • Steady (non-reversing) vortex, \(T{=}3\): never wins — worst band error from \(t=0\), fastest \(\min|\nabla\psi|\) flattening, and the first to annihilate the interface (\(h{=}1/64\): \(t\approx2.65\); meshWave 2.85; the other four reach \(T{=}3\)).
  • Verdict: the indispensable control — and a defensible choice only when \(\mathbf{U}\) is prescribed and the scenario effectively reverses.
The final-time reading rewards reversible transport distortion; the half-time and non-reversing readings expose it. Keep this asymmetry in mind: it frames every per-model verdict that follows.

Model anisotropicDiffusion — motivation

Problem: propagate \(\mathbf{U}_\Sigma\) off \(\Sigma\) so it stops varying along \(\hat{\mathbf{n}}\) — using only machinery a FVM code already owns.

Idea: one elliptic solve. Diffusion with \(\mathbf{D}=\hat{\mathbf{n}}\otimes\hat{\mathbf{n}}+\varepsilon\mathbf{I}\) conducts strongly along each normal ray and only \(\varepsilon\)-weakly across: its steady state equalizes \(\mathbf{U}_{\text{ext}}\) along the rays.

Regularized normal-aligned harmonic extension (source header credits Kummer). One fvm::laplacian, standard symmetric solvers, max principle ⇒ bounded by the seed data.

The picture is the whole model: a diffusion ellipse with its long axis glued to the local interface normal. In the limit eps -> 0 diffusion acts ONLY along rays, so the steady state is ray-wise constant = the extension property. eps regularizes the tangential (and 2D-empty) directions so the operator stays uniformly elliptic.

anisotropicDiffusion — the model

\[ \nabla\!\cdot\!\big(\mathbf{D}\,\nabla\mathbf{U}_{\text{ext}}\big)=\mathbf{0}, \qquad \mathbf{D}=\hat{\mathbf{n}}\otimes\hat{\mathbf{n}}+\varepsilon\,\mathbf{I}, \qquad \mathbf{U}_{\text{ext}}\big|_{\text{seed}}=\mathbf{U}_\Sigma \]
  • Why it extends: as \(\varepsilon\!\to\!0\) the solve minimizes \(\int_\Omega\big|(\hat{\mathbf{n}}\cdot\nabla)\mathbf{U}_{\text{ext}}\big|^2\mathrm{d}V\) — the normal-constancy defect itself is the Dirichlet energy of \(\mathbf{n}\otimes\mathbf{n}\)-diffusion.
  • Guarantee: \((\hat{\mathbf{n}}\cdot\nabla)\mathbf{U}_{\text{ext}}=0\) only approximately: the interior error is linear in \(\varepsilon\) (regular perturbation) ⇒ any fixed \(\varepsilon\) is an \(h\)-independent error floor.
  • Failure modes: (i) the \(\varepsilon\)-floor; (ii) even with \(\varepsilon=c\,h\), the discrete cross-diffusion of a near-rank-1 tensor Laplacian is itself \(\sim h\) (Droniou M3AS 24 (2014)) — the model cannot get below it; (iii) one-sided error (out/in \(\approx2.7\)): outside a convex \(\Sigma\) the rays diverge and under-constrain the exterior.
  • Safety: elliptic max principle — \(|\mathbf{U}_{\text{ext}}|\) is bounded by the seed data. This model is never unstable, merely inconsistent.
The energy view is the cleanest way to see both the strength (a variational characterization of the extension property) and the weakness (eps trades well-posedness against consistency linearly, and the discretization of the rank-1 limit adds its own O(h) cross-diffusion).

anisotropicDiffusion — discretization (UFVM)

  • \(\hat{\mathbf{n}}=\nabla\psi/|\nabla\psi|\) (least-squares gradient); \(\mathbf{D}=\) sqr(nHat) + eps*I as a volSymmTensorField; epsilonModel cellSize: \(\varepsilon_c=\varepsilon\,h_c\) (the measured configuration; fixed = legacy \(h\)-independent floor)
  • implicit anisotropic Laplacian fvm::laplacian(D, Uext): face sum \(\sum_f\mathbf{D}_f(\nabla\mathbf{U}_{\text{ext}})_f\!\cdot\!\mathbf{S}_f\) (Gauss linear \(\mathbf{D}_f\), orthogonal snGrad)
  • interface Dirichlet in the assembled matrix: fvMatrix::setValues(seedCells, UΣ) — row := identity, RHS := seed value; no submesh; nAnchorLayers extra pinned layers available (measured default 0)
  • whole-domain solve, zeroGradient outer BC; the shared \(C^1\) cosine fade (updateFlux) blends \(\mathbf{U}_{\text{ext}}\!\to\!\mathbf{U}\) beyond the band
  • solver from fvSolution → "Uext.*": PBiCGStab/DIC with a per-step relative tolerance (previous \(\mathbf{U}_{\text{ext}}\) = initial guess) — a tight absolute tolerance costs ~430 iterations/solve for no accuracy gain; GAMG stalls on the near-rank-1 \(\mathbf{D}\)
\[ \sum_{f}\, \mathbf{D}_f\,\big(\nabla\mathbf{U}_{\text{ext}}\big)_f\!\cdot\!\mathbf{S}_f = \mathbf{0}, \qquad \mathbf{U}_{\text{ext}}|_{\text{seed}}=\mathbf{U}_\Sigma \]

anisotropicDiffusion — formulation & algorithm

Whole-domain harmonic extension with a rank-deficient tensor conductivity:

\[ \nabla\!\cdot(\mathbf D\,\nabla\mathbf U_{\text{ext}})=\mathbf 0,\quad \mathbf D=\hat{\mathbf n}\otimes\hat{\mathbf n}+\varepsilon\mathbf I \] \[ \varepsilon_c=\varepsilon\,h_c\ (\text{cellSize}),\qquad \mathbf U_{\text{ext}}\big|_{\text{seed}}=\mathbf U_\Sigma\ (\text{Dirichlet}) \]

Eigenvalues \(1+\varepsilon\) along \(\hat{\mathbf n}\), \(\varepsilon\) tangential: strong normal transport, weak lateral smearing.

  1. Build \(\hat{\mathbf n}\) and cell size \(h_c\)
  2. eps field: epsilon_ or epsilon_*cellSize_c
  3. Assemble \(\mathbf D=\)sqr(nHat_) + eps*I (volSymmTensorField)
  4. Implicit fvm::laplacian(D, Uext) → UextEqn
  5. Dirichlet: UextEqn.setValues(seedCells, U_Σ)
  6. Solve PBiCGStab/DIC, controls from fvSolution "Uext.*"
  7. Cosine fade of \(\mathbf U_{\text{ext}}\) outside the narrow band

velocityExtension/anisotropicDiffusion.C — D = sqr(nHat_) + eps*symmTensor::I; natural zeroGradient at domain patches, Dirichlet only at the single interface layer.

The anisotropic-diffusion extension solves one steady tensor Laplacian over the whole domain. The conductivity D is a rank-one projector n-outer-n plus a small isotropic regularizer epsilon*I, so its eigenvalues are one-plus-epsilon along the normal and epsilon in the two tangential directions. Diffusion is therefore strongly directional: information from the interface seed cells is carried along the normal rays with almost no lateral bleeding. The seed cells hold the interpolated interface velocity U-Sigma and are pinned as Dirichlet constraints directly in the matrix via fvMatrix::setValues, while the domain boundaries stay natural zeroGradient. Epsilon can be a fixed absolute value or scale with the local cell size, eps_c = epsilon*h_c, which restores O(h) mesh consistency. The near-rank-one system is solved with PBiCGStab/DIC using a per-step relative tolerance taken from fvSolution's Uext.* entry, never hardcoded in C++. Finally a cosine taper fades the extended field to zero outside the narrow band.

Model pseudoTime — motivation (Adalsteinsson–Sethian)

Problem: the elliptic extension smears tangentially and floors at \(\varepsilon\). The extension property is a statement about transport along rays — so discretize it as transport.

Idea: carry \(\mathbf{U}_\Sigma\) outward along the characteristics \(\mathbf{w}=\operatorname{sign}(\psi)\hat{\mathbf{n}}\), marching a pseudo-time PDE towards its steady state. Upwinding respects the causality: information flows from \(\Sigma\) outward, front by front.

Adalsteinsson & Sethian JCP 148 (1999); PDE form with \(\operatorname{sign}(\psi)\): Peng et al. JCP 155 (1999).

The transport view is the classical one. The sketch already contains the model's measured failure: the fronts advance one front per pseudo-step, and with the study settings the total reach is 2 cells inside a 3-cell band -- the shaded fraction keeps the RAW velocity forever, which is why the static ratio pins at 0.47 regardless of h.

pseudoTime — the model

\[ \frac{\partial \mathbf{U}_{\text{ext}}}{\partial\tau} + \operatorname{sign}(\psi)\,(\hat{\mathbf{n}}\cdot\nabla)\,\mathbf{U}_{\text{ext}}=\mathbf{0}, \qquad \mathbf{U}_{\text{ext}}\big|_{\text{seed}}=\mathbf{U}_\Sigma \]
  • Why it extends: the steady state satisfies \((\hat{\mathbf{n}}\cdot\nabla)\mathbf{U}_{\text{ext}}=0\) wherever the march has arrived; the characteristics of \(\mathbf{w}=\operatorname{sign}(\psi)\hat{\mathbf{n}}\) all leave \(\Sigma\), so Dirichlet data at the seed layer determines everything downstream.
  • Failure mode 1 — truncated reach: \(n_{\text{iter}}\) steps of size \(\Delta\tau\) advance \(\approx n_{\text{iter}}\Delta\tau\) cells; anything farther keeps the raw velocity. A fixed fraction of the band is never extended — inconsistency by construction.
  • Failure mode 2 — \(\mathbf{w}\) is not solenoidal: \(\nabla\!\cdot\!(\operatorname{sign}(\psi)\hat{\mathbf{n}}) =\operatorname{sign}(\psi)\,\kappa\) + a jump at \(\Sigma\). A conservative discretization adds the spurious compression \(\mathbf{U}_{\text{ext}}\nabla\!\cdot\!\mathbf{w}\) — the historical \(\sim\!10^{108}\) blow-up of this very model. The cure is the non-conservative (advective) assembly.

Same lesson as the \(\psi\)-equation: extension PDEs transport values, they do not conserve fluxes — discretize \((\mathbf{w}\!\cdot\!\nabla)\), never \(\nabla\!\cdot\!(\mathbf{w}\,\cdot)\), when \(\nabla\!\cdot\!\mathbf{w}\neq0\).

Two independent failure modes: one of consistency (reach), one of stability (conservative form of a non-solenoidal transport). The second was fixed and is part of the Conclusions story; the first is intrinsic to pseudo-time marching and motivates the next stack (steadyUpwind).

pseudoTime — discretization (UFVM, implicit backward Euler)

  • propagation flux phiW = fvc::interpolate(w) & Sf, \(\mathbf{w}=\operatorname{sign}(\psi)\hat{\mathbf{n}}\)
  • non-conservative advection assembled as \((\mathbf{w}\!\cdot\!\nabla)\mathbf{U}_{\text{ext}} = \nabla\!\cdot\!(\phi_W\mathbf{U}_{\text{ext}}) - \mathbf{U}_{\text{ext}}\,(\nabla\!\cdot\!\phi_W)\) — fvmDiv(phiW, Uext) - fvm::Sp(divW, Uext)

  • Dirichlet seeds setValues(seedCells, UΣ) re-imposed every iteration; \(n_{\text{iter}}\) outer solves
  • solver from fvSolution → "Uext.*": PBiCGStab/DILU — asymmetric but diagonally dominant, ~3 iterations per march step
\[ \tfrac{1}{\Delta\tau}\mathbf{U}_{\text{ext}}^{k+1} + \big(\mathbf{w}\!\cdot\!\nabla\big)^{\text{up}}\mathbf{U}_{\text{ext}}^{k+1} = \tfrac{1}{\Delta\tau}\mathbf{U}_{\text{ext}}^{k}, \qquad k = 0,\dots,n_{\text{iter}}-1 \]

pseudoTime — formulation & algorithm

\[ \frac{\partial\mathbf U_{\text{ext}}}{\partial\tau}+\operatorname{sign}(\psi)\,(\hat{\mathbf n}\cdot\nabla)\mathbf U_{\text{ext}}=\mathbf 0,\quad \mathbf w=\operatorname{sign}(\psi)\,\hat{\mathbf n} \] \[ (\mathbf w\cdot\nabla)\mathbf U_{\text{ext}}=\underbrace{\nabla\!\cdot(\phi_W\mathbf U_{\text{ext}})-\mathbf U_{\text{ext}}(\nabla\!\cdot\phi_W)}_{\text{non-conservative}},\quad \phi_W=\mathbf w_f\!\cdot\mathbf S_f \] \[ \tfrac{1}{\Delta\tau\,h}\,\mathbf U + \nabla\!\cdot(\phi_W\mathbf U) - (\nabla\!\cdot\phi_W)\,\mathbf U = \tfrac{1}{\Delta\tau\,h}\,\mathbf U^{\text{prev}} \]
  1. Build march field w = sign(psi)*nHat.
  2. Flux phiW = interpolate(w)&Sf; divergence divW = fvc::div(phiW).
  3. For k = 1..nIterations: assemble implicit upwind backward-Euler
    fvm::Sp(1/(dTau*h),U) + fvm::div(phiW,U) - fvm::Sp(divW,U) == (1/(dTau*h))*U.prevIter(); setValues(seed, U_Sigma); solve().
  4. Fade U_ext away from Σ to blend with the bulk field.

The -U_ext (∇·phiW) correction subtracts the spurious source from the non-solenoidal march field w; without it the implicit upwind system diverges (~1e108 blow-up).

pseudoTime extends the interface velocity into the bulk by pseudo-time-marching a transport equation whose characteristics are the signed normals w = sign(psi) n_hat. Since w is not divergence-free, the naive div(phiW, U) discretization injects a fake U_ext*div(phiW) source; the fvm::Sp(divW, U) term cancels it exactly, converting the conservative divergence into the intended non-conservative advection (w.grad)U. Backward-Euler in pseudo-time gives an unconditionally stable implicit upwind solve; the seed value U_Sigma on the interface is pinned each iteration via setValues, and after nIterations the solution is constant along each ray so U_ext is a faithful normal extension. A final fade blends it into the surrounding field.

Model steadyUpwind — motivation: one solve, infinite reach

Problem: pseudoTime reaches \(n_{\text{iter}}\Delta\tau\) cells — a fixed band fraction is never updated (static ratio pinned at 0.47).

Idea: solve the steady limit directly. Every characteristic of \(\mathbf{w}=\operatorname{sign}(\psi)\hat{\mathbf{n}}\) emanates from \(\Sigma\): the upwind dependency graph is acyclic, so the implicit upwind matrix is an M-matrix permutable to block-lower-triangular form — one linear solve propagates the seed data to the whole domain.

The implicit twin of fast marching / fast sweeping: Zhao et al. JCP 127 (1996); Peng et al. JCP 155 (1999); Aslam, Luo & Zhao SISC 36 (2014).

The graph argument is the entire model: seed cell s determines cell 1, which determines 2, which determines 3 -- a topological order by distance from Sigma exists because no characteristic ever returns to the interface. An M-matrix in that order is block-lower-triangular, so DILU/BiCGStab converges in a handful of iterations and the reach is unbounded. This is fast sweeping expressed as a single fvMatrix.

steadyUpwind — the model

\[ \operatorname{sign}(\psi)\,(\hat{\mathbf{n}}\cdot\nabla)\,\mathbf{U}_{\text{ext}} = \mathbf{0}, \qquad \mathbf{U}_{\text{ext}}\big|_{\text{seed}} = \mathbf{U}_\Sigma \]
  • Why it extends: the steady limit of the pseudo-time PDE — the extension property is the equation; no truncation, no reach parameter. Well-posed because the boundary (seed) data sits exactly where all characteristics originate.
  • Guarantee: \((\hat{\mathbf{n}}\cdot\nabla)\mathbf{U}_{\text{ext}}=0\) asymptotically, at the order of the transport scheme (upwind: \(O(h)\)).
  • Failure mode 1 — the discrete skeleton: cells at local maxima of \(|\psi|\) have no upwind neighbour → a (near-)zero matrix row. Cure: a tiny zero-inflow guard \(\lambda\) relaxing such rows to their current value.
  • Failure mode 2 — the seed staircase: Dirichlet data pinned at cell centres at varying distances from \(\Sigma\) carries \(O(1)\) gradient noise; the steady transport propagates it unchanged along characteristics — and it emerges under refinement as cross-characteristic upwind diffusion shrinks (Chopp SISC 2009: invest in anchoring, keep transport simple).
Skeleton rows are a genuinely discrete phenomenon: continuum characteristics never collide except on a measure-zero set, but on a mesh the "ridge" cells see outflow on all faces. The lambda guard is the minimal regularization: it leaves transported rows untouched to 1e-6/h.

steadyUpwind — discretization (UFVM) + a measured warning

  • Assembled exactly like the \(\psi\)-equation (advective form of a non-solenoidal transport), plus the guard:
\[ \underbrace{\nabla\!\cdot\!(\phi_W\,\mathbf{q})}_{\texttt{fvm::div(phiW,q)}} \;-\;\underbrace{\mathbf{q}\,(\nabla\!\cdot\!\phi_W)}_{\texttt{fvm::Sp(divW,q)}} \;+\;\underbrace{\lambda\,\mathbf{q}}_{\texttt{fvm::Sp}} \;=\;\underbrace{\lambda\,\mathbf{q}^{\,k}}_{\text{RHS}}, \qquad \lambda=\frac{10^{-6}}{h_c} \]
  • divergence scheme from fvSchemes (div(velExtPhiW,Uext), study token: upwind / linearUpwind); solver from fvSolution "Uext.*" (PBiCGStab/DILU — a handful of iterations on the near-triangular matrix)
  • nDefCorrExt defect-correction passes converge the deferred (higher-order \(-\) upwind) flux, under-relaxed by defCorrRelax = 0.7 between passes
  • Measured negative result: the linearUpwind deferred correction DIVERGES on the steady equation (static \(e\) grows to \(\sim\!10^2\); under-relaxation does not save it) — unlike the \(\psi\)-equation there is no fvm::ddt mass matrix to damp the fixed-point iteration. Upwind is the safe default; second order comes from the geometric route (closestPoint) instead.

steadyUpwind — algorithm

  1. Build w = sign(psi)*n_hat; face flux phiW, divW = fvc::div(phiW); zero-inflow guard lambda = 1e-6/h.
  2. For pass = 1..nDefCorrExt assemble the advective UFVM system fvm::div(phiW,q) - fvm::Sp(divW,q) + fvm::Sp(lambda,q) == lambda*q.
  3. q.setValues(seed, U_Sigma) — pin the interface seed layer as Dirichlet.
  4. Solve (PBiCGStab + DILU) — near-triangular M-matrix, one implicit solve, infinite reach.
  5. Under-relax by 0.7 between passes; upwind interpolation is default.

steadyUpwind::solveSteady() — code (the family operator)

void Foam::steadyUpwind::solveSteady(volVectorField& q,
    const labelUList& fixedCells, const UList<vector>& fixedVals,
    const volVectorField* source)
{
    // w = sign(psi) n -- NOT solenoidal; its flux and compression:
    forAll(w, c) w[c] = ((psi_[c] < 0) ? -1.0 : 1.0)*nHat_[c];
    const surfaceScalarField phiW("velExtPhiW", fvc::interpolate(w) & mesh_.Sf());
    const volScalarField divW("velExtDivW", fvc::div(phiW));
    // zero-inflow guard: discrete-skeleton cells (local max |psi|) have no
    // upwind neighbour -> near-zero row; lambda relaxes them to themselves.
    forAll(lambda, c) lambda[c] = zeroInflowGuard_/cellSize_[c];   // 1e-6/h

    vectorField qPrev(q.primitiveField());
    for (label corr = 0; corr < nDefCorrExt_; ++corr)
    {
        fvVectorMatrix qEqn
        (
            fvm::div(phiW, q)     // scheme: fvSchemes div(velExtPhiW,Uext)
          - fvm::Sp(divW, q)      // advective form: (w.grad)q, not div(w q)
          + fvm::Sp(lambda, q)
         == lambda*q              // guard RHS: relax to the current value
        );
        if (source) qEqn -= *source;            // Aslam cascade stage RHS
        qEqn.setValues(fixedCells, fixedVals);  // seed Dirichlet in the matrix
        qEqn.solve();                           // fvSolution "Uext.*"

        if (corr < nDefCorrExt_ - 1)   // damp the deferred correction (the
        {                              // steady fixed point rings undamped)
            q.primitiveFieldRef() = defCorrRelax_*q.primitiveField()
                                  + (1.0 - defCorrRelax_)*qPrev;
            qPrev = q.primitiveField();
        }
    }
}

  • linearUpwind deferred correction diverges on the steady equation (no ddt damping) — upwind is the default; the second-order ambition moves to the geometric route.
  • Reversed vortex (\(T{=}2\), \(N{=}256\)): 0.105 / 0.4% — healthy mid-pack.
  • Steady vortex: keeps the interface alive to \(T{=}3\).
  • Roles it earned: the PDE fallback of the family and the fill operator inside closestPoint — infinite reach and graceful parallel behaviour make it the ideal backstop even though it never wins outright.

Model steadyUpwindLinear — motivation: the Aslam cascade

Problem: a constant-along-rays extension is only \(O(h)\) faithful to the physical \(\mathbf{U}\) near \(\Sigma\).

Idea (Aslam JCP 193 (2004)): extend the normal derivative first, then integrate it along the rays:

  1. \(V=\hat{\mathbf{n}}\cdot\nabla\mathbf{U}\) at the seed layer
  2. extend \(V\): \(\operatorname{sign}(\psi)(\hat{\mathbf{n}}\cdot\nabla)V=0\)
  3. integrate: \(\operatorname{sign}(\psi)(\hat{\mathbf{n}}\cdot\nabla) \mathbf{U}_{\text{ext}}=\operatorname{sign}(\psi)\,V_{\text{ext}}\)

\(\mathbf{U}_{\text{ext}}\) is then linear along each ray — \(O(h^2)\) by construction. The PDE counterpart of the closest-point model.

The cascade is the natural "next order" of the steady transport: same operator, applied twice, second pass with the extended derivative as a source. Along each ray the ODE dU/ds = V_ext with constant V_ext integrates to a straight line matching value AND slope at the interface.

steadyUpwindLinear — model & discretization

\[ \text{(1)}\; V=\hat{\mathbf{n}}\cdot\nabla\mathbf{U}\big|_{\text{seed}} \quad\Rightarrow\quad \text{(2)}\; \operatorname{sign}(\psi)(\hat{\mathbf{n}}\cdot\nabla)V=0 \quad\Rightarrow\quad \text{(3)}\; \operatorname{sign}(\psi)(\hat{\mathbf{n}}\cdot\nabla)\mathbf{U}_{\text{ext}} =\operatorname{sign}(\psi)\,V_{\text{ext}} \]

  • Scheme-reuse trick: \(V\) is named "Uext" but unregistered, so its transport picks up the same div(velExtPhiW,Uext) entry — the phiExt=="phi" naming pattern again.
  • Seeds of both stages come from the interface layer (\(V\) and \(\mathbf{U}_\Sigma\) respectively), pinned via setValues.

steadyUpwindLinear — the Aslam cascade (and why it diverges)

Three-stage cascade, O(h²) by construction:

\[ V=\hat{\mathbf n}\cdot\nabla\mathbf U\big|_{\text{seed}} \] \[ \operatorname{sign}(\psi)\,(\hat{\mathbf n}\cdot\nabla)V=0 \] \[ \operatorname{sign}(\psi)\,(\hat{\mathbf n}\cdot\nabla)\mathbf U_{\text{ext}}=\operatorname{sign}(\psi)\,V_{\text{ext}} \]
  1. Stage 1 — normal derivative V = n̂·grad(U) at the seed (LSQ gradient, fvSchemes/velExtLSGrad).
  2. Stage 2 — extend V constant along the rays (steadyUpwind, no source).
  3. Stage 3 — integrate U_ext with sign(ψ)V_ext as RHS source (linear along rays). Intended O(h²).

Measured: DIVERGES (~10¹–10²). Differentiating already-noisy foot-point seeds, plus an undamped steady fixed point (no ddt mass matrix).

Documented negative result — excluded from the advected suite.

The Aslam cascade builds a second-order extension by first computing the normal derivative V at the seed, extending V constant along the characteristics, then integrating U_ext with V as a linear source. In principle this makes U_ext tangent to the true profile at Sigma, giving O(h squared) versus the O(h) flat constant extension. In practice it blows up to order ten-to-one-hundred: stage one differentiates foot-point seeds that are already noisy, amplifying that noise, and the steady formulation has no time-derivative mass matrix to damp the fixed point. We keep it in the paper as a documented negative result but exclude it from the advected test suite.

  • Static: diverges — \(e\sim10^{1}\!-\!10^{2}\), growing under refinement; excluded from the advected suite.

  • Why it stays in the deck (and the code): an \(O(h^2)\)-by-construction formulation is worthless if the iteration diverges — the boundary of the design space, documented. The model remains registered and measured in the static harness as the reproducible negative result.

Model closestPoint — motivation: skip the PDE

Problem: every PDE transport pollutes the extension with seed-staircase noise — measured as the non-convergence of stacks 2–5.

Idea: no transport at all. Each band cell walks to its own closest interface point by Newton descent on \(\psi\) and samples \(\mathbf{U}\) there. Cells on one normal ray share the foot point ⇒ \((\hat{\mathbf{n}}\cdot\nabla)\mathbf{U}_{\text{ext}}=0\) by construction — no seed noise, no scheme, no linear solve; embarrassingly parallel per cell.

Closest point method: Ruuth & Merriman JCP 227 (2008); degree-\(p\) interpolation \(\Rightarrow O(h^{p+1})\): Macdonald & Ruuth SISC 31 (2009); front-tracking practice: Marić et al. C&F 113 (2015).

The philosophical shift of the whole part: extension is a GEOMETRIC statement, so compute it geometrically. The guards in the sketch are exactly the ways a walk can lie: it can run away (path cap), it can stop descending (|psi| monotonicity), and it can leave the processor mesh -- the last is rescued by a one-layer zoneDistribute halo (next slides); only deeper excursions fall back to the PDE fill.

closestPoint — the model (the geometric guarantee)

\[ \mathbf{U}_{\text{ext}}(\mathbf{x}_c) = \mathbf{U}\big(\mathbf{x}_{fp}(\mathbf{x}_c)\big), \qquad \mathbf{x}_{fp} = \operatorname*{arg\,min}_{\mathbf{y}\in\Sigma}\|\mathbf{x}_c-\mathbf{y}\| \;\;\approx\;\; \mathbf{x} \leftarrow \mathbf{x} - \psi(\mathbf{x})\,\hat{\mathbf{n}}(\mathbf{x}) \]
  • Guarantee: cells on one normal ray share the foot point \(\Rightarrow\) \((\hat{\mathbf{n}}\cdot\nabla)\mathbf{U}_{\text{ext}}=\mathbf{0}\) by construction (not asymptotically) inside the foot-point reach — mesh-agnostic, the general answer for unstructured FVM.
  • Accuracy: set by interpolation only — degree-\(p\) interpolation of \(\mathbf{U}\) at \(\mathbf{x}_{fp}\) gives \(O(h^{p+1})\) (here: cell-point linear \(\Rightarrow O(h^2)\), and that is what the static harness measures).
  • Failure modes: (i) the skeleton — where normal rays collide the descent diverges; (ii) ψ must be near-SDF: one Newton step is exact only for \(|\nabla\psi|=1\), a degraded \(\psi\) bends the walk; (iii) the foot point may lie on another processor — rescued by a one-layer zoneDistribute halo (next slide); only walks deeper than one remote layer still fail.
  • Graceful degradation: every failed cell is filled by the steadyUpwind solve pinned at all successful cells — the geometric data becomes the Dirichlet anchor set of the PDE backstop.
Note the division of labour: geometry where geometry is sound, transport where it is not. The steady operator that could not win on its own (seed staircase) is excellent as a FILLER, because the closest-point successes anchor it densely through the band.

closestPoint — discretization (UFVM)

  • Newton walk per band cell along the local normal: each step interpolates \(\psi\) at the iterate (interpolationCellPoint, IDW), steps \(\mathbf{x}\leftarrow\mathbf{x}-\psi(\mathbf{x})\hat{\mathbf{n}}(c_x)\), and re-localizes with findCell so \(\hat{\mathbf{n}}\), \(\psi\) are always evaluated in the cell containing the iterate (a frozen starting normal is too crude across the band); \(n_{\text{descent}}\) steps.
  • Guards (in walk order): path cap \(|\mathbf{x}-\mathbf{x}_c|\le\) cpMaxDist\(\cdot n_{\text{layers}}h_c\) (=1.5·3·h); findCell < 0 ⇒ try the halo (below), else fail; non-decreasing \(|\psi|\) ⇒ diverging descent. Acceptance: \(|\psi(\mathbf{x}_{fp})|<\) cpTol\(\cdot h_c\) (=0.1·h).
  • MPI halo (parallel only; zoneDistribute, the plicRDF machinery, Scheufler–Roenby JCP 383 (2019)): one cell-point-cell layer of remote \((\mathbf{C},\psi,\nabla\psi,\mathbf{U},\nabla\mathbf{U})\) around the band. Steps are sub-stepped at \(0.9\,h_c\) so the stencil anchor tracks the true exit cell; off-mesh iterates continue on first-order Taylor data at the nearest remote cell within cpHaloReach\(\cdot h\) (= same order as the local cell-point interpolation). Serial path untouched — bit-identical regression.
  • Fill: failures (counted, reported: skeleton, path cap, deeper-than-halo) → one solveSteady with all successes as Dirichlet data.
  • Band and fade are \(|\psi|\)-based: band \(=\{|\psi|\le(n_{\text{layers}}\!+\!1)h_c\}\) (guard layer keeps gradient stencils interior); \(h_c\) = min face-neighbour centre distance, not \(\sqrt[3]{V}\) (which mis-scales every length on a 2D mesh of thickness \(t\)).

closestPoint — formulation & algorithm

Foot-point value; no PDE where the geometry reaches:

\[ \mathbf U_{\text{ext}}(\mathbf x_c)=\mathbf U\big(\mathbf x_{fp}\big),\quad \mathbf x_{fp}=\arg\min_{\mathbf y\in\Sigma}\|\mathbf x_c-\mathbf y\| \]

Newton descent along the local normal:

\[ \mathbf x\leftarrow\mathbf x-\psi(\mathbf x)\,\hat{\mathbf n}(\mathbf x) \]

accept if \(|\psi(\mathbf x_{fp})|<\text{cpTol}\,h\); cap \(|\mathbf x_{fp}-\mathbf x_c|\le\text{cpMaxDist}\,n_{\text{layers}}h\); require \(|\psi|\) decreasing.

\((\hat{\mathbf n}\cdot\nabla)\mathbf U_{\text{ext}}=0\) holds by construction: all cells on one descent ray share the foot. Algorithm → next slide.

closestPoint: each band cell walks to its own foot point on Sigma by Newton descent and copies back the interface velocity. Equations + geometry here; the per-step algorithm follows on the next slide.

closestPoint — algorithm

  1. each band cell: x=x_c, cx=c, apsi=|psi_c|.
  2. step x←x−ψ(x)n̂(x); findCell re-localizes, n̂=nHat_[cx] re-evaluated per cell.
  3. guards: path cap; non-decreasing \(|\psi|\) aborts; off-mesh → zoneDistribute one-layer halo, Taylor continuation \(\psi\approx\psi_j+\nabla\psi_j\!\cdot\!(x-C_j)\).
  4. accept \(|\psi|<\text{cpTol}\,h\) → Uext=interpolationCellPoint of U at foot, \(O(h^2)\).
  5. skeleton / deep failures → solveSteady (steadyUpwind) pinned at all successes.

closestPoint.C / extend() · closest-point method Ruuth & Merriman JCP 227 (2008); degree-\(p\)→\(O(h^{p+1})\) Macdonald & Ruuth SISC 31 (2009); halo via zoneDistribute Scheufler & Roenby JCP 383 (2019).

Newton descent x - psi*n_hat; findCell re-localizes, normal re-read per cell. Guards: path cap, non-decreasing |psi|, parallel halo (0.9-cell substeps, Taylor continuation at nearest remote cell within cpHaloReach*h). Accepted cells interpolate U at foot (cell-point, O(h^2)); failures filled by steadyUpwind pinned at successes. Defaults cpTol 0.1, cpMaxDist 1.5, cpHaloReach 1.5.

closestPoint::extend() — code

// PARALLEL: one CPC halo layer of remote (C, psi, grad psi, U, grad U) around
// the band (zoneDistribute; as in plicRDF), fetched once per correct().
// Per band cell: cx >= 0 = local containing cell; cx = -1 = halo mode (data
// cell jg); cLast = last LOCAL cell (halo stencil anchor + reach scale).
const label nIter = haveHalo ? nDescent_ + nLayers_ + 2 : nDescent_;
for (label it = 0; it < nIter; ++it)                   // Newton walk
{
    scalar psix;  vector nx;
    if (cx >= 0) { psix = psiInterp.interpolate(x, cx);  nx = nHat_[cx]; }
    else {                            // halo: 1st-order TAYLOR at nearest
        psix = ccPsi[jg] + (ccGPsi[jg] & (x - ccC[jg]));   // remote cell
        nx = ccGPsi[jg]/Foam::max(Foam::mag(ccGPsi[jg]), SMALL); }

    vector dx = -psix*nx;
    if (haveHalo) {                   // sub-step ~1 cell: cLast tracks the
        const scalar mS = 0.9*cellSize_[cLast >= 0 ? cLast : c];  // true
        if (Foam::mag(dx) > mS) dx *= mS/Foam::mag(dx); }    // exit cell
    const point xNew = x + dx;
    if (Foam::mag(xNew - C[c]) > maxDist) { ok = false; break; } // path cap

    const label cn = mesh_.findCell(xNew);             // local first ...
    label jn = -1;
    if (cn < 0) { jn = nearestHalo(xNew, cLast);       // ... then halo
                  if (jn < 0) { ok = false; break; } } // deeper -> fill
    // |psi| decrease guard (1e-3 h slack on Taylor steps), then advance:
    x = xNew;  cx = cn;  jg = jn;  if (cn >= 0) cLast = cn;
}
if (ok && apsi < cpTol_*hc)            // acceptance: |psi(x_fp)| < 0.1 h
{
    Uext_[c] = (cx >= 0) ? Uinterp.interpolate(x, cx)  // U at foot point
             : ccU[jg] + ((x - ccC[jg]) & ccGU[jg]);   // Taylor U (halo)
    fixedCells.append(c);  fixedVals.append(Uext_[c]);
}
else ++nFailed;
// ... after the loop over band cells:
solveSteady(Uext_, fixedCells, fixedVals);   // pinned at ALL successes

Two evaluation operators, one walk: local cell-point interpolation while findCell succeeds, first-order Taylor at the nearest halo cell after a processor crossing (same order) — the sub-stepping keeps the halo anchor cLast on the true exit cell — the PDE backstop only sees skeleton, path-cap and deeper-than-halo cells.

closestPoint — measured verdict

  • Static: the only convergent model. \(e_{L_2}\): 0.27 \(\to\) 0.0045 over \(h=1/32\to1/256\) — \(\approx O(h^2)\), ratio \(\to10^{-3}\), within 4× of the exact-extension reference.
  • Reversed vortex (\(T{=}2\), \(N{=}256\)): 0.104 / 0.015% — the best volume conservation of the family.
  • Extreme \(T{=}8\) inverts the story: 0.61 / 55% loss — after long unredistanced advection \(\psi\) is far from a signed distance, the Newton walks bend and fail en masse. Redistancing is this model’s missing partner.
  • Steady vortex: the lowest band error until \(t\approx1.2\) (5–10× below none); degrades once the filament band self-overlaps.
  • MPI (measured, steady vortex, np=4/scotch): the zoneDistribute halo + sub-stepped walk cut the fallback share 5.32% \(\to\) 1.28% at \(N{=}64\) and to 0.26% at \(N{=}128\) — essentially the 0.15% serial floor (skeleton + tolerance only); parallel–serial \(L_\infty\psi\) discrepancy 1.19×10−3 \(\to\) 3.37×10−4; serial results bit-identical.
  • Verdict: the reference model wherever \(\psi\) is maintained — highest accuracy, geometric guarantee, parallel-complete up to one halo layer with a graceful PDE fallback beyond; couple with redistancing for long-time robustness.
The T=8 inversion is the cleanest demonstration in the whole study that a method's hypothesis set matters: the model assumes psi is close to a signed distance; violate that long enough and the geometric walk -- its very strength -- becomes the failure channel, while dumb transport (meshWave) keeps chugging.

Model meshWave — motivation: the parallel-native wave

Problem: closestPoint walks fail at processor boundaries and near the skeleton; the PDE fill needs a linear solve. Can the closest-point idea run on machinery that is parallel-correct by design?

Idea: OpenFOAM already owns one: FaceCellWave — the wallDist engine. Seed every \(\psi\)-sign-change face with its foot point and the interface velocity there as a payload; the wave delivers the nearest seed’s payload to every cell, distance-ordered like fast marching — across processor, cyclic and AMI boundaries natively.

Adalsteinsson & Sethian JCP 148 (1999) reinterpreted through OpenFOAM’s wave engine (MeshWave<wallPointData<vector>>).

wallDist computes distance to walls by exactly this wave; here the wall is Sigma (sign-change faces) and the transported info additionally carries the interface velocity. Where the wave fronts of two seeds meet, the nearer seed wins -- a discrete Voronoi diagram of the seed set, which IS the closest-point map quantized to seeds.

meshWave — the model

\[ \mathbf{U}_{\text{ext}}(\mathbf{x}_c) = \mathbf{U}\big(\mathbf{x}_{fp}(f^*)\big), \qquad f^* = \operatorname*{arg\,min}_{f\,\in\,\text{seed faces}} \big\|\mathbf{x}_c - \mathbf{x}_{fp}(f)\big\|, \qquad \mathbf{x}_{fp}(f)=\mathbf{x}_f-\psi_f\,\hat{\mathbf{n}}_f \]
  • What it is: the closest-point map quantized to the seed set — a discrete Voronoi assignment: every cell inherits the payload of its nearest seed’s foot point.
  • Guarantee: \((\hat{\mathbf{n}}\cdot\nabla)\mathbf{U}_{\text{ext}}\approx0\) to \(O(h)\): the nearest seed is within \(O(h)\) of the true foot point along \(\Sigma\), so the sampled velocity is \(O(h)\) off — a flat, non-convergent but uniformly bounded extension error.
  • By-products: exact band distances for free (wallPointData::distSqr) and an initial guess for other models.
  • No solve, no walk, no failure channel: the wave visits each face O(1) times; parallel, cyclic and AMI transfers are the engine’s own (FaceCellWave) — the model inherits fifteen years of production hardening.
Contrast with closestPoint: same geometric target, opposite accuracy/robustness trade. closestPoint refines the foot point per cell (O(h^2)) but owns its failure handling; meshWave accepts O(h) quantization and in exchange NOTHING can fail -- every cell always receives the nearest valid payload.

meshWave — discretization (UFVM)

  • Seeds: every internal face with \(\psi_{\text{own}}\psi_{\text{nei}}<0\); face foot point \(\mathbf{x}_{fp}=\mathbf{x}_f-\psi_f\hat{\mathbf{n}}_f\) (\(\psi_f\), \(\hat{\mathbf{n}}_f\) linearly interpolated); payload = wallPointData<vector>(fp, U(fp), |x_f-fp|²) with \(\mathbf{U}(\mathbf{x}_{fp})\) by cell-point (IDW) interpolation (owner-cell value if findCell fails).
  • Wave: MeshWave<wallPointData<vector>> over the whole mesh (cheap; \(n_{\text{totalCells}}+1\) iterations cap); each visited cell/face keeps the payload with the smaller distance — the distance-ordered relaxation that makes it the FVM-native fast marching.
  • Consumption: only band cells overwrite \(\mathbf{U}_{\text{ext}}\) with the wave payload; the shared cosine fade (updateFlux) handles the transition beyond.
  • Stock OpenFOAM classes end to end: MeshWave.H, wallPointData.H (patterns from patchDataWave / fvc::sweep) — zero new parallel code in leia.

meshWave — formulation & algorithm

\[ \mathbf U_{\text{ext}}(\mathbf x_c)=\mathbf U\big(\mathbf x_{fp}(f^{*})\big),\quad f^{*}=\arg\min_{f\in\text{seed}}\lVert\mathbf x_c-\mathbf x_{fp}(f)\rVert \] \[ \mathbf x_{fp}(f)=\mathbf x_f-\psi_f\,\hat{\mathbf n}_f,\qquad (\hat{\mathbf n}\cdot\nabla)\mathbf U_{\text{ext}}=\mathcal O(h) \]
  1. Seeds: internal faces with psi_own*psi_nei < 0 (sign-change across the face).
  2. Face foot fp = Cf - psi_f*n_hat_f; payload = (fp, U(fp) via cell-point interpolation, |Cf-fp|^2).
  3. MeshWave (FaceCellWave) propagates fronts in distance order; each cell keeps the minimum-distance payload — native across processor / cyclic / AMI boundaries.
  4. Band cells ← nearest seed's velocity \(\mathbf U(\mathbf x_{fp}(f^{*}))\).
  5. Fade toward the outer band edge.

Solve-free; \(\mathcal O(h)\) nearest-seed quantization error; never diverges. velocityExtension/meshWave

meshWave is the solve-free extension. It marks interface-adjacent faces where the level-set changes sign as seeds, projects each seed face centre back onto the interface along the normal to get a foot point, and attaches the interpolated velocity at that foot as a payload. OpenFOAM's FaceCellWave then floods the narrow band in strict distance order, so every band cell inherits the velocity of its single nearest seed. This tessellates the band into nearest-seed Voronoi regions. Because it is a graph flood rather than a linear solve, it never diverges and works transparently across processor, cyclic, and AMI patches; the price is O(h) piecewise-constant quantization from picking exactly one nearest seed, softened by the fade near the band edge.

Three measurement-infrastructure bugs were found and fixed on the way (each visible as a spurious plateau/ring): (1) cbrt(V) != h on a 2D mesh of thickness 0.1 mis-scaled every length (region spanned 4.4-8.8 cells instead of 3) -- fixed with per-cell min face-neighbour distance; (2) the cell-hop band under-covered the |psi| shell at corners -- fixed with a |psi|-based band + one guard layer; (3) fade must start beyond the guard layer so gradient stencils stay interior. Why the legacy models cannot converge — diagnosis

  • pseudoTime: reach failure, not discretization. The march covers \(n_{\text{iter}}\,\Delta\tau = 10\times0.2 = 2\) cells < the 3-cell band: a fixed fraction of the band never receives the extension — ratio pinned at ≈0.47 for every \(h\). Cure: the steady solve (steadyUpwind) with infinite reach.
  • anisotropicDiffusion: regularization floor. Interior error is linear in \(\varepsilon\) (regular perturbation), so fixed \(\varepsilon=10^{-3}\) gives an \(h\)-independent floor; even \(\varepsilon=c\,h\) leaves ratio 0.55–0.72 — the mesh-induced cross-diffusion of fvm::laplacian on a near-rank-1 tensor is itself \(\sim h\) (the measured grid-aligned artifacts; Droniou M3AS 2014).
  • Both: the seed staircase. Dirichlet data pinned at cell centres at varying distances from \(\Sigma\) carries \(O(1)\) gradient noise into every PDE transport; the geometric closestPoint assignment has no transport to pollute (Chopp SISC 2009: invest in anchoring, keep transport simple).

The landscape — extension methods & what fits UFVM

  • Fast-marching extension (Adalsteinsson–Sethian JCP 148 '99; Chopp SISC '01/'09): heap-ordered causal updates — outside fvMatrix, first order; its FVM-native analogue is our meshWave (FaceCellWave).
  • PDE extension (Zhao et al. '96; Peng et al. '99): pseudo-time or steady transport — our pseudoTime/steadyUpwind; implicit-steady = fast sweeping (Aslam–Luo–Zhao SISC '14).
  • Extrapolation cascade (Aslam JCP 193 '04; McCaslin et al. JCP 274 '14): \(O(h^2)\!-\!O(h^3)\) along normals — our steadyUpwindLinear; needs a damped/sweeping form on UFVM (measured divergent in the undamped implicit form).
  • Closest point (Ruuth–Merriman JCP 227 '08; Macdonald–Ruuth SISC '09; LENT: Marić et al. C&F 113 '15): geometric, \(O(h^{p+1})\) — our closestPoint, the measured winner.
  • Skipped deliberately: heap-FMM/OUM ports (Kimmel–Sethian; Sethian–Vladimirsky — alien to fvMatrix, first order anyway) and elliptic/Hilbertian extension (de Gournay SICON '06 — \(\mathbf{n}\cdot\nabla\mathbf{u}_{\text{ext}}\not\to0\): wrong target).

Well-posedness of the velocity-extension evolution: Bothe & Soga arXiv:2412.13567. Gap this work fills: a measured \(\ge\)2nd-order \(\mathbf{n}\cdot\nabla\mathbf{u}_{\text{ext}}\to0\) extension native to general polyhedral FVM meshes.

Anchoring: foot-pointed Dirichlet layers (nAnchorLayers)

Hypothesis: pinning only the single interface-cell layer leaves the PDE stencil of every interface-adjacent cell mixing solved and pinned values — kinks in \(\mathbf{U}_{\text{ext}}\) right where it matters.

Remedy tested: foot-point (steepest descent + IDW interpolation, identical to the interface layer) the velocities of nAnchorLayers adjacent cell layers and pin them as Dirichlet data too (interfaceExtension::buildBand, dict entry nAnchorLayers, default 0; swept \(\{0,1,2\}\)).

Measured: refuted as the dominant error. \(\|e\|_{L_2}\) changes by <3% (aniso, \(N=64\): 2.951→2.958); \(\|e\|_{L_\infty}\) worsens (\(N=256\): 10.0→13.1 for 0→2 layers). The transition ring dominates, not seed-stencil kinks.

More pinned interpolated data creates more local gradients (hence the Linf growth). nAnchorLayers stays available (default 0); the anchor-1/2 field montages (figures/static_e_anchor1/2.png) are visually indistinguishable from anchor 0.

Why the reversed vortex loses volume at large \(T\)

The prescribed flow is time-reversible: the exact interface returns to the circle at \(t=T\). Numerically, the vortex winds the blob into a filament whose width shrinks with the integrated strain (\(\propto T\)).

  • At large \(T\) the filament thins below the cell; at \(t\approx T/2\) (max deformation) the level-set zero contour pinches off — a numerical topological change.
  • A pinch destroys interface information; with a non-conservative level set (leia has no mass fix) it is irreversible — the reversed flow cannot rebuild it.
  • Resolution moves the pinch threshold (\(T=8\), none): \(N\le64\) lose everything, \(N=128\) loses 24%, \(N=256\) keeps ~98% — but the required \(N\) grows with \(T\) (filament width \(\propto 1/T\)) at 8× cost per level, and coarse-mesh losses remain irreversible.

Identical for none / anisotropicDiffusion / pseudoTime ⇒ base level-set limit. The robust cure for under-resolved interfaces is a conservative / topology-aware method (CLSVOF, conservative level set) rather than brute-force refinement.

The continuous problem is reversible (diffeomorphic flow map); the loss is a NUMERICAL topological change from under-resolution, irreversible once it happens.

Runtime Model Selection

The maths and discretization of every model are settled. This section shows how they plug together: one runtime-selectable object per concept, chosen from a dictionary, discovered from the object registry.

Runtime selection design

  • Abstract base phaseIndicator with an RTS table + New(const fvMesh&)
  • Concrete: geometric, detrixheAslam, heaviside
  • Chosen from fvSolution:
    levelSet / phaseIndicator / type
  • Fields (psi, alpha, NarrowBand, nc) discovered from the object registry by configurable name keys.
OpenFOAM's declareRunTimeSelectionTable / addToRunTimeSelectionTable macros. Models look up their fields via mesh.lookupObject, with the field names taken from the sub-dict (getOrDefault), so nothing is hard-wired.

Same pattern, everywhere

RTS + object registry = pluggable, KISS.

Adding a new model = one class + addToRunTimeSelectionTable + a dict entry. No solver edits. The same idiom recurs for surfaceTensionForce and schemes.

Architecture map

One library of runtime-selectable models feeds two thin solvers; a Snakemake suite verifies them.

Take-away: the design is a small library of interchangeable numerical models (RTS + registry) that two solvers compose, with a reproducible verification harness on top. New physics/schemes plug in without touching the solvers.

Add your own model — without touching existing code

The velocity-extension hierarchy is runtime-selected (open/closed): a new model is a new class, no edits to existing ones.

  1. Derive from interfaceExtension (reuse the seed / band / flux backbone) — or from velocityExtension for full control.
  2. TypeName("myModel"); + a (const fvMesh&) constructor.
  3. addToRunTimeSelectionTable(velocityExtension, myModel, Mesh);
  4. Implement the one pure-virtual extend() (fill Uext_ in the band from the pinned seed layer).
  5. Add the .C to src/leiaLevelSet/Make/files; wmake.
  6. Select at runtime: levelSet{ velocityExtension{ type myModel; } }.

Templates: anisotropicDiffusion.C (one linear solve) and pseudoTime.C (iterative march).
