\title{The SDPLS level-set method for two-phase flows: source-term control
of the signed-distance property without interface displacement}

\author[tuda]{Tomislav Mari\'{c}}
\author[tuda]{Mathis Fricke}
\author[tuda]{Dieter Bothe}
\address[tuda]{Mathematical Modeling and Analysis, TU Darmstadt, Germany}

\begin{abstract}
Reinitialization displaces the interface: the zero level set and the
narrow-band values are the same degrees of freedom, so any rewrite of the
band trades transport accuracy for reconstruction accuracy and pays a
spurious volume change per redistancing step. The SDPLS method avoids the
trade entirely: a source term $S = f_{nl}(\psilev^n)\,\psilev$ that
vanishes identically on the zero level set controls the gradient of
$\psilev$ through the transport equation itself --- zero interface
displacement by construction. We report the first valid measurement of what
that source does to the level-set gradient error in this framework. Two
implementation defects had to be removed first: the source was applied with a
\emph{reversed sign} on its explicit branch, so it doubled the gradient drift
instead of cancelling it, and the error metric measured $\gradpsi$ with a
\emph{cell-limited} gradient operator that returns exactly zero at a local
extremum --- a different operator from the one the source controls. With both
corrected, and with every arm run on one discretization, the strain-cancelling
source reduces the band gradient error by $31\times$ on the finest mesh of a
seven-rung 2D vortex ladder and, decisively, \emph{converges under refinement
where the sourceless baseline diverges} ($+0.74$ against $-0.26$), at no cost
in volume conservation. A third contribution is negative and methodological:
the reversed (oscillating) benchmark on which such source terms are
conventionally assessed cannot answer this question at all. Because the
interfacial stretching integrates to zero over the period, the final-time error
of a passively advected level set cancels by construction, and the same case
run reversed reports the sourceless baseline as $477\times$ \emph{more}
accurate. Every measurement here is therefore made on a non-reversing flow.
\end{abstract}

\section{Introduction}
Level-set transport degrades $\gradpsi$: the gradient magnitude obeys
$\mathrm d\ln\gradpsi/\mathrm dt = -(\nhat\cdot\nabla\mathbf{v}\cdot\nhat)$
along characteristics, so an initially signed-distance field stops being one as
soon as the interface strains. Classical reinitialization
\cite{sussman1994,russo2000} restores $\gradpsi\approx1$ by rewriting the band,
and pays for it with interface displacement --- the cost measured in the
companion GRL line. The SDPLS idea is to leave the interface alone and act
only where the level set is free: a source proportional to $\psilev$ itself.

\section{Method}
\subsection{The source term}
\begin{equation}
  \partial_t \psilev + \nabla\cdot(\mathbf{v}\psilev)
  - \psilev\,\nabla\cdot\mathbf{v} = f_{nl}(\psilev^n)\,\psilev .
  \label{eq:sdpls}
\end{equation}
Because $S \propto \psilev$, the source vanishes identically on the zero
level set: the interface evolves by transport alone. Two choices are
implemented:
\begin{itemize}
  \item \textbf{R}: $f_{nl} = (\nhat\cdot\nabla\mathbf{v}\cdot\nhat)$
    cancels the normal-strain drift of $\gradpsi$ (the SDPLS model);
  \item \textbf{beta}: $f_{nl} = \beta - \gradpsi$ relaxes
    $\gradpsi \to \beta$ (the convected level-set idea \cite{ville2011}).
\end{itemize}
The two differ structurally, and the difference is visible in the results.
\textbf{R} cancels the drift and leaves no preferred value, so its interfacial
equilibrium is set only by the cancellation residual. \textbf{beta} relaxes
towards $g_\ast = \beta - a$ with $a = \nhat\cdot\nabla\mathbf{v}\cdot\nhat$:
its target is \emph{velocity dependent}, and therefore wrong wherever the
interface strains.

The source gradients are discretized under dedicated scheme keywords
(\texttt{gradPsiSdpls}, \texttt{gradUSdpls}) --- never silently coupled to
the advection scheme's limited $\nabla\psilev$, which is a different operator
serving a different purpose (Section~\ref{sec:metric}).

\subsection{Linearization and stability}
$S = f_{nl}(\psilev^n)\,\psilev^{n+1}$ splits into an explicit part
$S_c$ and an implicit diagonal part $S_p$: \texttt{explicit}
($S_c = f_{nl}\psilev^n$, $S_p = 0$), \texttt{simpleLinearImplicit}
($S_p = f_{nl}$) and \texttt{strictNegativeSpLinearImplicit}
($S_p = \min(f_{nl},0)$, $S_c = \max(f_{nl},0)\psilev^n$, diagonally dominant
by construction).

All three discretize the \emph{same} continuum term, so at $\psilev=\psilev^n$
they must apply the same physical source. That identity is now asserted by a
standalone unit test on an affine exact solution
(\texttt{leiaTestSdplsSource}); it is what exposed the two defects of
Section~\ref{sec:defects}, and it is the reason the measured orders of
Section~\ref{sec:verification} agree to three digits between linearizations.

\subsection{Defect correction}
Second-order deferred div schemes (\texttt{linearUpwind}) carry their
second-order part as an explicit right-hand-side source, so one pass is
first-order in practice. The same loop also Picard-iterates the SDPLS
nonlinearity, because $f_{nl}$ is relinearized from the current iterate at
every pass. Both argue for at least three passes; all results below use
\texttt{nDefCorr} $=3$.

\section{Two defects that invalidated the previous record}
\label{sec:defects}

\subsection{A reversed sign on the explicit branch}
\texttt{fvMatrix::operator==} subtracts the right-hand matrix termwise, so a
contribution written into \texttt{source\_} enters the transport equation with
a \emph{minus} --- OpenFOAM's own \texttt{fvm::Su} encodes this by doing
\texttt{source\_ -= V*su}. The assembled equation was therefore
$\mathrm D\psilev/\mathrm Dt = S_p\psilev^{n+1} - S_c$. Consequently
\texttt{explicit} \emph{doubled} the gradient drift instead of cancelling it,
and \texttt{strictNegativeSpLinearImplicit} did so on its $f_{nl}>0$ branch
only. \texttt{simpleLinearImplicit} ($S_c=0$) was never affected --- which is
precisely why the defect survived, because every published mesh ladder used
\texttt{strictNegativeSp}.

The signature is unambiguous in the stored output: with no source
$\ln g = -\!\int\! a$, with correct SDPLS $0$, and with a reversed sign
$-2\!\int\! a$. Measured at $N=512$, the ratio
$\ln g(\text{SDPLS:R})/\ln g(\text{noSource})$ was
$2.003,\ 2.002,\ 2.001,\ 1.997$ at $t = 0.05,\ 0.10,\ 0.20,\ 0.30$.

\subsection{A use-after-free in the same branch}
\texttt{explicitDiscretization::Sc} returned a \texttt{tmp} bound to a
temporary destroyed at the end of the return statement, so the values later
multiplied by the cell volumes were whatever remained in the freed block. It
was caught by the affine unit test: \texttt{explicit} disagreed with
\texttt{strictNegativeSp} in the regime where the two have identical $S_c$ and
$S_p$ by construction, which no legitimate discretization difference can
produce.

\subsection{The metric measured the wrong operator}
\label{sec:metric}
The gradient-error function objects called the \emph{unnamed}
\texttt{fvc::grad(psi)}, which resolves to the advection scheme's
\texttt{grad(psi)} --- \texttt{cellLimited leastSquares 1}. A cell-limited
(minmod) gradient returns \emph{exactly zero} at a local extremum, so the
metric reported $\gradpsi = 0$ and $e = 1$ there regardless of the true
gradient. On an \emph{exact analytic signed distance} the old metric reported
$E^{\max}_{\nabla\psi} = 1.000$ and $\min\gradpsi = 0.000$ at every resolution
from $N=32$ to $512$. Both objects now use a dedicated unlimited keyword; on
the same exact field the maximum error becomes $0.667$ (the circle-centre
kink, finite and mesh-independent) and the band $L_2$ error retains its
$O(h^2)$ behaviour ($6.4\times10^{-3} \to 2.5\times10^{-5}$ over
$N=32\to512$; fitted orders $1.97,\ 2.04,\ 2.01$).

\subsection{One discretization, or no comparison}
Arms run with different level-set advection schemes are different methods. An
earlier attempt at the 3D studies pinned \texttt{div(phi,psi) Gauss linear}
while the 2D studies used \texttt{Gauss linearUpwind grad(psi)}, and nothing in
the curated output recorded the difference; the 3D result appeared to show the
source achieving nothing. Every run reported here records the discretization it
actually used, parsed from its rendered \texttt{fvSchemes}, and a gate
(\texttt{make check-discretization}) asserts that a study group used one:
114 finite-volume cases, one discretization, for the results below.

\section{Verification}
\label{sec:verification}

Non-reversing flows: the 2D single vortex, the 3D shear and the 3D LeVeque
deformation, each on a uniform refinement ladder at $\mathrm{CFL} = 0.5$, with
\texttt{noSource}, \textbf{R} and \textbf{beta} $\times$ the two admissible
linearizations. The reversal is switched off deliberately, and the reason is
the subject of the next paragraph.

\paragraph{Which instant measures what.}
\label{par:reversal}
On a reversed flow the velocity carries a $\cos(\pi t/\tau)$ factor, so
$\int_0^T a\,\mathrm dt = 0$ along every interfacial trajectory. That
cancellation corrupts one column, and it is worth being precise about which,
because the reversal is also the only thing that makes a shape error definable.

At $t=T/2$ the factor has been positive throughout, so $\int_0^{T/2} a\,\mathrm dt$
is at its \emph{maximum}: the interface is maximally deformed and nothing has
cancelled. Gradient and volume error are both honest measurements there. At
$t=T$ the interface has returned to its starting position, which is what makes
the shape error --- measured against the initial condition --- meaningful at
all; volume conservation remains a valid check. But the $t=T$ \emph{gradient}
error compares a source's residual against an exactly-cancelling control: a
passively advected level set is carried back to its initial signed-distance
state, while \emph{any} source does work on $\psilev$ along the trajectory that
the return leg does not undo. That column rewards whichever scheme accumulated
the most \emph{recoverable} error, and it is not reported in this work.

The distortion is not small. On the 2D vortex at $T=2$, band gradient error at
$t=T$:
\begin{center}
\begin{tabular}{lcccccr}
\toprule
$N$ & 32 & 64 & 128 & 256 & 512 & order \\
\midrule
no source     & 0.122 & 0.072 & 0.012 & 0.0013 & \textbf{0.0001} & $+2.63$ \\
\textbf{R}    & 0.306 & 0.258 & 0.148 & 0.084  & 0.048           & $+0.70$ \\
\texttt{beta} & 0.275 & 0.330 & 0.361 & 2.805  & 6.897           & $-1.24$ \\
\bottomrule
\end{tabular}
\end{center}
Read at face value this says the baseline is $477\times$ more accurate than
\textbf{R} and that no source term is warranted. Removing the reversal and
changing nothing else inverts it: the baseline's order goes $+2.63 \to -0.26$
while \textbf{R}'s is unchanged at $+0.74$.

That non-reversing run is retained as a \emph{control}, and it establishes that
the corruption is confined to the $t=T$ gradient column rather than
contaminating the reversed run as a whole. Compare the reversed $t=T/2$ orders
against the same case run non-reversing to $t=T$:
\begin{center}
\begin{tabular}{lrr}
\toprule
band gradient order & reversed, $t=T/2$ & non-reversing, $t=T$ \\
\midrule
\textbf{R}    & $+1.228$ & $+0.74$ \\
no source     & $-0.094$ & $-0.26$ \\
\texttt{beta} & $+0.087$ & $-0.04$ \\
\bottomrule
\end{tabular}
\end{center}
Two independent configurations, agreeing in sign and in ranking on all three
arms, against a reversed $t=T$ column that disagrees with both. The measurement
protocol follows: the gradient error is read at $t=T/2$, the shape error at
$t=T$, and volume conservation at both. The $t=T$ gradient error is suppressed
in the generated tables rather than left to the reader's judgement.

Without a source the level set loses the signed-distance property monotonically
under refinement: the band mean of $\gradpsi$ runs $2.15 \to 3.52$ as $N$ goes
$32 \to 256$. The vortex winds the interface into a filament, the stretching
term $a$ steepens $\gradpsi$ without bound, and nothing in the sourceless
equation restores it. Only \textbf{R} converges, and it is $31\times$ more
accurate than the baseline on the finest mesh.

Volume conservation is not paid for to buy this. From $N=128$ upward
\textbf{R} conserves volume better than the baseline as well as converging
faster in it ($+3.37$ against $+1.39$). The volume orders are fitted over
$N \ge 64$: at $N=32$ the sourceless baseline itself loses $24.5\%$ of the
phase volume, and a run that has lost a quarter of its volume is not a
convergence data point whatever its gradient error reads.

Geometric (shape) error is \emph{not} reportable on this non-reversing control:
it is defined against the initial condition, which is the correct answer at
$t=T$ only if the flow returns the interface there. That is precisely why the
reversed configuration is retained for the shape measurement rather than
discarded --- the two configurations answer different questions, and the
protocol above assigns each metric to the instant at which it is defined.
Shape error at $t=T$ does benefit from the return leg, in the same way the
gradient error does; it is reported as the conventional benchmark it is, and
the signed-distance claim of this work rests on the $t=T/2$ column and on the
non-reversing control, neither of which does.

\paragraph{The result.}
The sourceless band gradient error \emph{grows} under refinement while the
strain-cancelling source's \emph{shrinks}. That inversion is the substance of
the method: it is the difference between a level set that degrades as the mesh
improves and one that does not. It is also invisible on a reversed flow, which
is why it went unmeasured for so long.

\paragraph{Where the missing order is not.}
\label{par:ablation}
\textbf{R} converges, but at $+0.74$ --- well short of the formal order of the
discretization, and the shortfall needs an explanation rather than a caveat.
Two candidates can be eliminated by measurement. The first is the
\emph{reconstruction gradient} of the \texttt{linearUpwind} advection: it is
cell-limited by default, and a limiter that clips at local extrema is an
obvious order-killer for a quantity whose extrema are the thing being measured.
A 56-case ablation replacing it with cell-limited Gauss, unlimited least
squares and face-limited least squares, holding everything else fixed over the
full $N = 32\ldots256$ ladder, gives fitted orders of $0.740$, $0.740$, $0.743$
and $0.658$. Removing the limiter entirely moves the order by $0.003$. It does
improve the error by about $5\%$ at every rung, so the limiter costs a little
accuracy and no order at all. The sourceless arm is equally indifferent
($-0.255$ against $-0.240$). Face limiting is the only variant that changes
anything, and it is worse in both order and error. The second candidate is the
time integration, and it is excluded by inspection: these runs use
\texttt{CrankNicolson}, which is second order, not first-order Euler, so there
is no first-order temporal cap to explain a sub-unit slope.

The default arm of this ablation reproduces the $+0.74$ of the main ladder to
three digits from an independently configured study, which is the cross-check
that the two are measuring the same thing.

What remains is not yet resolved, and two things are worth separating. On the
measurement side, the narrow band is the set of sign-change cells, so it is
attached to the interface and its physical width shrinks like $O(h)$: the norm
is taken over a different region at every rung, which is the right region to
care about but not a fixed domain on which a classical order is defined. On the
method side, the cancellation is built from $\mathbf{n} = \nabla\psilev/\gradpsi$,
so the accuracy of the strain that the source cancels is bounded by the accuracy
of the gradient it is computed from --- the source cannot cancel a stretching
term more precisely than it can estimate it. Distinguishing these requires a
fixed-width band and a normal-error measurement, and neither is claimed here.

\paragraph{Why \texttt{beta} fails.}
\label{par:beta}
\texttt{beta} is not unstable on this flow and it is not under-resolved; it
converges accurately to the wrong value. Differentiating~\eqref{eq:sdpls} along
the interface with $g = \gradpsi$ gives $Dg/Dt = g\,(f_{nl} - a)$. The
strain-cancelling choice $f_{nl} = a$ makes this identically zero, so $g$ is
left wherever it started, namely at $1$. The choice $f_{nl} = \beta - g$ makes
it logistic,
\begin{equation}
\frac{Dg}{Dt} = g\,(\beta - g - a),
\label{eq:betalogistic}
\end{equation}
with a stable fixed point at $g^{*} = \beta - a$ and an unstable one at $g=0$.
The stable target is set by the \emph{flow}, not by the signed-distance
condition, and equals the value actually wanted only where $\beta = 1 + a$.
Since $a$ varies over the interface and over time, no constant $\beta$ is
correct except by coincidence.

The prediction is quantitative and it holds. On the non-reversing vortex with
$\beta = 1$ and $a$ measured per time step from the registered strain field,
the band mean of $\gradpsi$ at $t=T$ against the predicted $\beta - a$:
\begin{center}
\begin{tabular}{lccccccc}
\toprule
$N$ & 32 & 45 & 64 & 90 & 128 & 181 & 256 \\
\midrule
measured $g$          & 1.600 & 1.851 & 2.023 & 2.080 & 2.001 & 1.922 & 1.927 \\
predicted $\beta - a$ & 1.820 & 1.790 & 1.804 & 1.836 & 1.841 & 1.872 & 1.866 \\
\addlinespace
\textbf{R} control    & 0.953 & 0.995 & 1.041 & 1.075 & 1.109 & 1.073 & 1.021 \\
\bottomrule
\end{tabular}
\end{center}
The measured equilibrium tracks $\beta - a$ to between $2.7\%$ and $13.3\%$ and
shows no tendency toward $1$ under refinement, while the \textbf{R} control on
the same flow, subject to the same strain, holds $g$ at $1.02$. This is why
\texttt{beta}'s band gradient error saturates near $0.98$ and its order is
$-0.04$: refinement cannot remove an error that the equation is asking for. A
28-case sweep over $\beta \in \{0.5, 1.0, 1.5, 2.0\}$ confirms the target
independently --- the band mean shifts one-for-one with $\beta$, measured slope
$0.938$ against a predicted $1$.

Equation~\eqref{eq:betalogistic} also accounts for the failure mode seen on the
reversed runs. Where $\beta - a < 0$ the target is negative, so the source
drives $g \to 0$; but $g = 0$ is the \emph{unstable} fixed point, so those cells
grow without bound once the strain changes sign, with band maxima reaching
$154.9$. Flattening and blow-up are one mechanism, not two.

\paragraph{Linearization agreement.}
The two admissible linearizations agree to three digits on every fitted order
($0.698/0.699$, $0.477/0.478$, $-0.169/-0.169$), as they must: they discretize
the same continuum term. Disagreement between them was the symptom that led to
the defects of Section~\ref{sec:defects}.

\subsection{Where the error lives}
\label{sec:atlas}
A fitted order says that a method improved; it does not say \emph{where}.
Figure~\ref{fig:graderr-atlas} maps the signed-distance error
$\bigl|\gradpsi-1\bigr|$ over the whole domain for the strain-cancelling source
and for \texttt{beta}, across the refinement ladder, at the initial instant, at
maximal deformation, and after the flow has reversed.

The two behave differently in a way the aggregate norms compress away. For
\texttt{R} the error collapses over a growing neighbourhood of the recovered
interface as the mesh refines --- at $N=512$, $t=T$ the field around the zero
level set is four to five decades below unity --- and the recovered
$\psilev=0$ contour is a clean circle. For \texttt{beta} the bulk error stays
at $O(1)$ at every resolution, and the recovered contour carries additional
internal structure rather than closing on the initial circle. That is the
expected signature of a flattening level set: where $\gradpsi$ collapses, the
interface position error scales like $e_\psilev/\gradpsi$, so small value noise
produces spurious zero crossings. It is the same statement as the band minimum,
$0.423$ for \texttt{beta} against $0.883$ for \texttt{R} at $N=512$, seen in
space instead of as a single number.

\paragraph{What two instants cannot show.}
The tables report $t=T/2$ and $t=T$. That suffices to fit an order and is not
enough to see a mechanism. Figure~\ref{fig:trajectory} plots the band statistics
at \emph{every} time step, together with the strain the source is reacting to,
and it exposes a failure the aggregates conceal. The band \emph{maximum} of
$\gradpsi$ peaks at $3.81$ for no source and at $1.23$ for \texttt{R}; for
\texttt{beta} it reaches $154.9$, and it is still $123.5$ at $t=T$. The band
mean at $t=T$ is $1.256$, so the blow-up is confined to a few cells and the mean
never reveals it.

It begins at $t \approx 1.03$ --- immediately after the flow reverses at $T/2$
--- and the gradient law says why. Where $a > \beta$ the source drives $g$ toward
zero, but $g=0$ is an \emph{unstable} fixed point of
$\mathrm{D}g/\mathrm{D}t = g(\beta - g - a)$ as soon as the strain changes sign
and $\beta - a > 0$: the flattened cells then grow exponentially. Flattening and
blow-up are the same mechanism seen on either side of the reversal, and the
right-hand panel shows the target $\beta - a$ is negative over part of the band
for $93\%$ of the time steps.

\paragraph{And it is triggered by refinement.}
The band maximum at $t=T$ across the ladder is the sharpest statement in this
paper about \texttt{beta}:
\begin{center}
\begin{tabular}{lccccc}
\toprule
$N$ & 32 & 64 & 128 & 256 & 512 \\
\midrule
\texttt{beta}     & 1.68 & 1.51 & 1.62 & \textbf{50.9} & \textbf{123.5} \\
\texttt{R}        & 1.40 & 1.42 & 1.22 & 1.15 & 1.11 \\
no source         & 1.10 & 1.18 & 1.03 & 1.002 & 1.0003 \\
\bottomrule
\end{tabular}
\end{center}
The blow-up is \emph{absent} at $N \le 128$ and appears between $N=128$ and
$N=256$, growing thereafter; the band minimum at $t=T$ falls to $0.0585$ at
$N=512$. \texttt{beta} is therefore acceptable on coarse meshes and fails on
fine ones, which is the opposite of convergence and cannot be detected by
running the coarse end of a ladder. Over the same refinement the
strain-cancelling source tightens monotonically toward unity from both sides,
and the sourceless run converges to $1.0003$ by time-reversal symmetry.

A caveat on the statistic: the band maximum is an extreme-value estimate, and
the band holds $O(N)$ cells, so a finer mesh samples the tail more thoroughly.
That cannot account for what is measured here --- a factor $31$ between $N=128$
and $N=256$ for a twofold refinement, against a twofold growth in sample size.

\section{Negative results}
Measured and documented in the companion deck. Retained:
\begin{itemize}
  \item \textbf{beta's target is structurally wrong}, and this is now measured
    rather than argued. Differentiating the transport equation and evaluating at
    $\psilev=0$ gives, for $g=\gradpsi$ and the interfacial normal strain
    $a = \nhat\cdot\nabla\mathbf{u}\cdot\nhat$,
    \[
      \frac{\mathrm{D}g}{\mathrm{D}t} \;=\; g\,(f_{nl} - a),
    \]
    so the strain-cancelling choice $f_{nl}=a$ makes $\mathrm{D}g/\mathrm{D}t=0$
    identically --- whatever error remains is numerical, which is why it
    converges --- while $f_{nl} = \beta - g$ has the fixed point
    $g_\ast = \beta - a$, set by the flow rather than by the mesh. Three
    consequences, all observed on the 2D reversed vortex:
    \begin{enumerate}
      \item The band mean $\gradpsi$ at maximal deformation is
        $1.516, 1.498, 1.478, 1.485, 1.481$ for $N = 32\ldots512$ --- flat to
        about $2\%$ over a sixteenfold refinement, against $1.071 \to 1.002$ for
        the strain-cancelling source. A residual vanishes with $h$; this does
        not.
      \item The measured band strain reaches $\max a = 2.77$ against $\beta=1$,
        so over part of the interface the fixed point $\beta - a$ is
        \emph{negative}. A magnitude cannot reach it, and $g$ is driven toward
        zero instead: the level set flattens hardest exactly where the flow
        stretches hardest. The band minimum, $0.423$ against $0.883$ for
        \texttt{R} at $N=512$, is that effect
        (Figure~\ref{fig:graderr-atlas}).
      \item On this reversible flow the sourceless drift cancels by
        time-reversal symmetry --- band mean $1.0000$ at $t=T$, $N=512$, with
        \texttt{R} at $0.9991$. \texttt{beta} gives $1.2562$ and degrades under
        refinement. It is the only arm that makes the reversal worse than doing
        nothing.
    \end{enumerate}
    None of this is interface displacement: volume and shape errors are at the
    $10^{-4}$ level or below for every arm at fine resolution
    (Figure~\ref{fig:alpha-atlas}).
  \item \textbf{A source term does not repair resolution.} Strain cancellation
    is exact only while the interface is resolved; near $\kappa h \sim 1$ the
    reconstructed normal, and hence $f_{nl}$, is unreliable.
  \item \textbf{The dead \texttt{limit} entry.} \texttt{limit} is read only by
    the tanh profile; \texttt{signedDistance} ignores it, so two studies built
    on it compared identical initial fields.
  \item \textbf{\texttt{sdplsBeta} requires an explicit \texttt{beta}} --- the
    missing-coefficient construction failure; explicit beats a hidden default.
\end{itemize}

Retracted, because they were artefacts of the defects of
Section~\ref{sec:defects} rather than properties of the method:
\begin{itemize}
  \item ``R over-flattening near the resolution limit'' and ``R controls
    steepening, not flattening'' --- both measured with the reversed-sign
    \texttt{strictNegativeSp} branch, which doubled the drift it was supposed
    to cancel.
  \item ``\texttt{beta} + \texttt{explicit} diverges at every CFL,
    $\Delta t$-independent'' --- \emph{falsified}, at the very configuration
    where it was made (Table~\ref{tab:agreement}): $N=128$, $T=2$,
    $\mathrm{CFL} \in \{0.1, 0.5, 1.0\}$. All three runs complete, and the
    explicit branch agrees with both implicit ones to five significant digits.
    The original divergence was produced by the reversed sign and the
    use-after-free that branch carried, not by anti-damped relaxation.
  \item Any verdict of the form ``SDPLS makes the band gradient error worse
    than no source'', which came from the same branch and, in the 3D case,
    from arms run on different advection schemes.
\end{itemize}

\section{Conclusions}
The SDPLS source controls $\gradpsi$ through the transport equation with zero
interface displacement by construction, and --- once the sign, the lifetime bug
and the measuring operator are corrected, and once every arm is run on one
discretization --- the strain-cancelling form converges on a non-reversing flow
where the sourceless baseline diverges, without paying for it in volume
conservation. The two linearizations agree, which is the internal consistency
check the defects had been violating.

The negative results are as load-bearing as the positive one. \texttt{beta} does
not fail through instability or under-resolution: it relaxes accurately to
$\beta - a$, a target set by the flow rather than by the signed-distance
condition, so a constant $\beta$ is correct only where $\beta = 1 + a$ and no
amount of refinement removes the resulting error. And the reversed benchmark
conventionally used to assess such source terms is structurally unable to
discriminate them, because the final-time error of a passively advected level
set cancels by time-reversal symmetry --- it reported the sourceless baseline
as $477\times$ more accurate than the source that, on the same case without the
reversal, is the only arm that converges.

What a source term still cannot do is manufacture resolution: the cancellation
is only as good as the normal it is built from.

\paragraph{Open.} The non-reversing 3D shear and LeVeque deformation ladders,
and an ablation isolating how much of the sub-unit convergence order
($+0.74$, short of the discretization's formal order) belongs to the source and
how much to the reconstruction gradient of the transport scheme, are in
progress and are not claimed here.
