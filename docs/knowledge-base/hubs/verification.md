# Verification methodology

[[index]] <- back

## The question this part answers

How does a number become a result here, how does a result become a decision, and how is a wrong result retracted so that nobody builds on it?

## Current verdict (2026-09-28)

The rules are in [CLAUDE.md](https://github.com/leia-openfoam/leia/blob/8867581/CLAUDE.md) and every one of them is written from an incident of this repository. The research loop: name the number, pre-register the read-out, cheapest discriminator first, one variable plus controls, check the measurement, report the whole vector ([CLAUDE.md, the research loop](https://github.com/leia-openfoam/leia/blob/8867581/CLAUDE.md#L409-L508)). The error vector is shape, volume, band gradient, spurious current and pressure jump together, in $L^2$ and $L^1$ only, read at the right instant ([[concepts/error-vector-and-read-out-instants]]). Any advection change runs a three-rung mesh convergence study and the standing regression set ([[concepts/richardson-ladders-and-orders]], [[concepts/advection-regression-set]]). Every new algorithm runs on four ranks before the cluster, and the coupled solver's decomposition is checked by the gate's seam arms ([[concepts/seam-checks-and-decomposition-invariance]]). A wrong setup voids its data ([[concepts/wrong-setup-voids]]); nothing is inert until a bit-identity run says so ([[concepts/bit-identity-and-inertness-gates]]); binaries, jobs and ssh output are tracked by id and artefact ([[concepts/cluster-provenance-and-binaries]]); solver logs are read by the classifier only ([[concepts/log-classifier-and-waiters]]); every curated number is regenerated by a committed script from an archived per-version data folder ([[concepts/data-archive-per-version]]). The method gates ([[concepts/method-gates]]) are the executable form: one 2D and one 3D study test every candidate against the production method on five arms with a verdict of four criteria. Two blind spots of the gate were found on 2026-09-28: the exact-1D closed form is None for every candidate, and the centred band metric is blind to the cell-scale mode.
