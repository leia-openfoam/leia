# Integral surface tension (CST) and the meta-law

> Verdict (2026-09-29). The conservative integral surface-tension model (CST) of Abu-Al-Saud, Popinet and Tchelepi builds the force as `-div(p I + sigma)` from the interface tangents at the face crossings of `psi = 0` ([doi:10.1016/j.jcp.2018.02.022](https://doi.org/10.1016/j.jcp.2018.02.022)). leia has it only as a 2D structured prototype ([SL article](https://github.com/leia-openfoam/leia/blob/d1e3414/docs/semi-lagrangian-level-set/sl-level-set-article/semiLagrangianLevelSet.tex#L1960-L1964), [`integralSurfaceTension.H`](https://github.com/leia-openfoam/leia/blob/d1e3414/src/leiaLevelSet/surfaceTensionForce/integralSurfaceTension.H#L29-L50)). On the stationary droplet at N = 64 it gives the only reachable discrete equilibrium of the record. The peak current `max|U|` decays from 3.3e-3 to 5e-7 m/s at t = 0.2 s, 25 times below the CSF plateau, and the Laplace jump is within 0.02 % ([SL article](https://github.com/leia-openfoam/leia/blob/d1e3414/docs/semi-lagrangian-level-set/sl-level-set-article/semiLagrangianLevelSet.tex#L1970-L1973)). The record gives no L1 or L2 for these arms. The current grows again after t = 0.25 s. At N = 128 the run diverges near t = 0.047 s, earlier than the CSF default at 0.105 s, and half the step moves the divergence to 0.050 s only ([SL article](https://github.com/leia-openfoam/leia/blob/d1e3414/docs/semi-lagrangian-level-set/sl-level-set-article/semiLagrangianLevelSet.tex#L1974-L1976), [negative deck 1/1](https://leia-openfoam.github.io/leia/decks/quadratic-semi-lagrangian-level-set-negative-results.html#/1/1)). On the translating droplet at N = 64 it becomes nonlinear within the first 1.4e-3 s ([RM](https://github.com/leia-openfoam/leia/blob/d1e3414/docs/capillary-level-set-research-roadmap.md#L393-L398)). The curvature-free conormal variant leaves a 49.45 % non-gradient residual after the raw projection, and its face-flux form fails at t = 0.0011 s at N = 64 ([RM](https://github.com/leia-openfoam/leia/blob/d1e3414/docs/capillary-level-set-research-roadmap.md#L222-L233), [RM](https://github.com/leia-openfoam/leia/blob/d1e3414/docs/capillary-level-set-research-roadmap.md#L429-L442)). The record reads the pattern as a meta-law: the better the static balance, the higher the dynamic feedback gain ([negative deck 4/3](https://leia-openfoam.github.io/leia/decks/quadratic-semi-lagrangian-level-set-negative-results.html#/4/3)). The cause it gives: the CST inputs still read the level-set profile ([SL article](https://github.com/leia-openfoam/leia/blob/d1e3414/docs/semi-lagrangian-level-set/sl-level-set-article/semiLagrangianLevelSet.tex#L1976-L1989)). A verbatim transcription of the paper has an inverted overall sign: this is the sign trap ([negative deck 4/1](https://leia-openfoam.github.io/leia/decks/quadratic-semi-lagrangian-level-set-negative-results.html#/4/1)). The model needs a structured `(i, j)` index space, so as written it is outside the unstructured-FVM constraint ([`integralSurfaceTension.C`](https://github.com/leia-openfoam/leia/blob/d1e3414/src/leiaLevelSet/surfaceTensionForce/integralSurfaceTension.C#L111-L172), [CLAUDE.md](https://github.com/leia-openfoam/leia/blob/d1e3414/CLAUDE.md#L404-L413)). The line is closed; production uses `reconstructedCurvature` ([[decisions/surface-tension-reconstructed-curvature]]).

## What it is

CST writes surface tension as the divergence of a stress, `-div(p I + sigma)`. The stress comes from the interface tangents at the crossings of `psi = 0` with the momentum control-volume faces. The paper adds pressure-jump corrections `gamma kappa~ s` at those crossings, so the curvature enters only there ([SL article](https://github.com/leia-openfoam/leia/blob/d1e3414/docs/semi-lagrangian-level-set/sl-level-set-article/semiLagrangianLevelSet.tex#L1960-L1964)). The switch `curvatureSource field | constant | none` isolates that correction for ablations ([`integralSurfaceTension.H`](https://github.com/leia-openfoam/leia/blob/d1e3414/src/leiaLevelSet/surfaceTensionForce/integralSurfaceTension.H#L89-L95)). With `none` the force is built from the tangents only; that is an ablation, not a complete curvature-free method ([RM](https://github.com/leia-openfoam/leia/blob/d1e3414/docs/capillary-level-set-research-roadmap.md#L190-L197)).

The conormal variant `integralConormalSurfaceTension` has no curvature. It builds one owner-oriented traction per cut face from the reconstructed interface segment and deposits equal and opposite cell forces ([RM](https://github.com/leia-openfoam/leia/blob/d1e3414/docs/capillary-level-set-research-roadmap.md#L214-L220)). Today it returns only the face flux `G_sigma,f = interpolate(f_sigma,c) . S_f`; the direct cell source is removed ([`integralConormalSurfaceTension.H`](https://github.com/leia-openfoam/leia/blob/d1e3414/src/leiaLevelSet/surfaceTensionForce/integralConormalSurfaceTension.H#L24-L36)).

The meta-law compares two quantities. The static balance is the level of the spurious current on the stationary droplet at the start or at the settled plateau. The dynamic gain is the growth of the same current in the coupled run. The record measured four deliveries at N = 64 and N = 128 ([negative deck 4/3](https://leia-openfoam.github.io/leia/decks/quadratic-semi-lagrangian-level-set-negative-results.html#/4/3)):

| delivery | static balance at N = 64 | coupled fate, N = 64 / N = 128 |
|---|---|---|
| arithmetic `kappa_f` with the smeared alpha (default) | worst, 4.5e-3 | most stable, 0.44 / 0.105 s |
| Kang `kappa_f` with the geometric alpha | 6 times better | grows at N = 64 |
| Kang `kappa_f` with the sharp Heaviside | 58 times better | 0.073 / 0.049 s |
| CST, sign-corrected | best, floor 5e-7 | grows again / 0.047 s |

The currents in this table are peak values `max|U|`, the only norm the record gives. The CSF plateau that the CST floor is compared with is `max|U| = 1.250e-5` m/s at N = 64 ([SL article](https://github.com/leia-openfoam/leia/blob/d1e3414/docs/semi-lagrangian-level-set/sl-level-set-article/semiLagrangianLevelSet.tex#L1851-L1853)). The Kang rows are in [[concepts/kang-gfm-and-sharp-heaviside]].

## Why it matters

1. It is the constructive counter-example: give the discretisation a reachable equilibrium, and the current decays by three and a half decades, reinitialisation-free ([SL deck 4/35](https://leia-openfoam.github.io/leia/decks/quadratic-semi-lagrangian-level-set.html#/4/35)). Of the tested deliveries it is the one closest to a variational statement, which motivates [[concepts/variational-capillary-force]] ([SL article](https://github.com/leia-openfoam/leia/blob/d1e3414/docs/semi-lagrangian-level-set/sl-level-set-article/semiLagrangianLevelSet.tex#L2666-L2675)).
2. It shows that a static balance is not evidence of dynamic stability. Kang and CST are four replications of the same tension ([SL deck 4/45](https://leia-openfoam.github.io/leia/decks/quadratic-semi-lagrangian-level-set.html#/4/45)).
3. The sign trap gave a rule: check the signed Laplace jump on a static droplet before any coupled run of a new force ([negative deck 6/2](https://leia-openfoam.github.io/leia/decks/quadratic-semi-lagrangian-level-set-negative-results.html#/6/2)).

2. The structured `(i, j)` addressing from the cell centres; the model stops with a fatal error on any mesh that is not one uniform block ([`integralSurfaceTension.C`](https://github.com/leia-openfoam/leia/blob/d1e3414/src/leiaLevelSet/surfaceTensionForce/integralSurfaceTension.C#L111-L172)).

## Why it failed, or why we think so

1. The inputs still read the level-set profile. The jump corrections interpolate the cell curvature to the crossings, and the tangents are unit vectors only while `|grad psi| = 1`. A reinitialisation-free transport does not keep that property, so the balance error grows as `gamma (|grad psi| - 1)/h^2` under refinement ([SL article](https://github.com/leia-openfoam/leia/blob/d1e3414/docs/semi-lagrangian-level-set/sl-level-set-article/semiLagrangianLevelSet.tex#L1976-L1983)). The paper caps this term with a threshold reinitialisation, which fires when the band L1 of `||grad psi| - 1|` exceeds `h^2`; leia has no such cap by design. The general lesson: an integral reformulation smooths a corrupted geometry, it does not create a missing signal ([PCS 3](https://github.com/leia-openfoam/leia/blob/d1e3414/docs/plan-curvature-stabilization.md#L371-L373)).
2. The record's reading of the meta-law: the arithmetic average and the smeared support act as a spatial low-pass filter on the curvature-error force. Every sharper delivery couples the perturbations of `psi` to the force more coherently ([SL article](https://github.com/leia-openfoam/leia/blob/d1e3414/docs/semi-lagrangian-level-set/sl-level-set-article/semiLagrangianLevelSet.tex#L1983-L1989)). This is an interpretation of four arms, not a separate measurement (HYPOTHESIS).
3. The curvature is not the only defect of the CST prototype. The exact curvature lowers its first impulse from 5.645e-2 to 3.707e-2 m/s only, and the run still fails ([RM](https://github.com/leia-openfoam/leia/blob/d1e3414/docs/capillary-level-set-research-roadmap.md#L209-L212)).
4. Global force conservation is necessary, not sufficient. A cell force sent through interpolation is not the face-wise gradient of one pressure jump; the next operator must build the scalar face flux directly from shared interface geometry ([RM](https://github.com/leia-openfoam/leia/blob/d1e3414/docs/capillary-level-set-research-roadmap.md#L436-L442), [RM P3](https://github.com/leia-openfoam/leia/blob/d1e3414/docs/capillary-level-set-research-roadmap.md#L572-L594)).
5. The sign trap. The printed relations of the paper have an inverted overall sign: its Eq. 8 has `+div(sigma)` against its own `-div(p I + sigma)`, and the Appendix B relations give `p_air = p_water + gamma kappa` on a signed-distance circle. The algorithms do not depend on the orientation of `psi`, so no sign convention corrects them, and the error metric of the paper does not see the sign ([negative deck 4/1](https://leia-openfoam.github.io/leia/decks/quadratic-semi-lagrangian-level-set-negative-results.html#/4/1)). The fix is one global sign flip on the assembled force ([SL article](https://github.com/leia-openfoam/leia/blob/d1e3414/docs/semi-lagrangian-level-set/sl-level-set-article/semiLagrangianLevelSet.tex#L1964-L1969)).

## Decisions

- The CST is not production and is not a candidate. It stays selectable as a 2D research prototype; the roadmap does not call either integral model an unstructured solution ([RM](https://github.com/leia-openfoam/leia/blob/d1e3414/docs/capillary-level-set-research-roadmap.md#L717-L722)).
- Do not generalise the structured `(i, j)` stencil by indexing arbitrary cells ([RM P3](https://github.com/leia-openfoam/leia/blob/d1e3414/docs/capillary-level-set-research-roadmap.md#L552-L555)).
- A new force passes a signed static Laplace-jump check before any coupled run ([negative deck 4/1](https://leia-openfoam.github.io/leia/decks/quadratic-semi-lagrangian-level-set-negative-results.html#/4/1)).

## Open questions

1. The configs, the commit and the binaries of the stationary CST runs at N = 64 and 128 are not recorded. The numbers exist only as text in the article, the decks and the case templates.
2. `normalizeGradient true` has been the code default since the import (8de7503, 2026-07-30). It targets the channel of item 1 above. The header states a stable run on a circle and on an algebraic ellipsoid. The record has no config or number for that run, and it does not say which setting the N = 64 and N = 128 runs used ([`integralSurfaceTension.H`](https://github.com/leia-openfoam/leia/blob/d1e3414/src/leiaLevelSet/surfaceTensionForce/integralSurfaceTension.H#L97-L106)).
3. Thirteen case templates still call CST "MEASURED SUPERIOR on the static droplet" and do not state the N = 128 result ([`fvSolution.template`](https://github.com/leia-openfoam/leia/blob/d1e3414/cases/stationaryDroplet2D/system/fvSolution.template#L219-L230)).
4. CST with the threshold reinitialisation of the paper was not run. The trigger was tested alone at N = 64. The metric floor of the Gauss gradient is 28 times the threshold, so the trigger fires at every step; the policy is pending ([negative deck 5/1](https://leia-openfoam.github.io/leia/decks/quadratic-semi-lagrangian-level-set-negative-results.html#/5/1), [[models/redistancer]]).
5. The unstructured operator of roadmap P3, one scalar face flux from shared interface geometry, has no implementation ([RM P3](https://github.com/leia-openfoam/leia/blob/d1e3414/docs/capillary-level-set-research-roadmap.md#L620-L645)).
