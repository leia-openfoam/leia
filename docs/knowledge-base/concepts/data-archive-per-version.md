# The data archive per software version

> Verdict (2026-09-29). Every number of the gradient-control pre-print comes from one folder of secondary data, `data/archive/shared-method-config-2026-09-01-192-g1150e68/`, with 116 files and 13 MB ([STATUS 11.16](https://github.com/leia-openfoam/leia/blob/d1e3414/STATUS.md#L4050-L4053)). The folder name is the version stamp of `libleiaCore` in the `leia.version` of the runs that produced the fixed 2D method gate ([archive README](https://github.com/leia-openfoam/leia/blob/d1e3414/docs/gradient-controlled-level-set/gcls-level-set-article/data/archive/shared-method-config-2026-09-01-192-g1150e68/README.md#L1-L9)). `figures/make_archive.py` writes the folder from the raw output. `figures/make_result_figures.py` and `make_gate_tables.py` write the figures and the tables from it. Nothing in it is typed by hand ([archive README](https://github.com/leia-openfoam/leia/blob/d1e3414/docs/gradient-controlled-level-set/gcls-level-set-article/data/archive/shared-method-config-2026-09-01-192-g1150e68/README.md#L3-L9)). `MANIFEST.csv` lists every file with its row count, size and SHA-256 ([same](https://github.com/leia-openfoam/leia/blob/d1e3414/docs/gradient-controlled-level-set/gcls-level-set-article/data/archive/shared-method-config-2026-09-01-192-g1150e68/README.md#L8-L9)). A new version of the pre-print gets a new folder, and an older folder is never overwritten ([archive README](https://github.com/leia-openfoam/leia/blob/d1e3414/docs/gradient-controlled-level-set/gcls-level-set-article/data/archive/shared-method-config-2026-09-01-192-g1150e68/README.md#L36-L37)). The convention is a stricter form of an older rule: every curated number under `docs/**/data/` is regenerated by a committed script from committed configs ([CLAUDE.md](https://github.com/leia-openfoam/leia/blob/d1e3414/CLAUDE.md#L809-L811)). Since 2026-09-28 the same script also writes the four findings on the semi-Lagrangian baseline into the data folders of the SL article ([`make_result_figures.py`](https://github.com/leia-openfoam/leia/blob/d1e3414/docs/gradient-controlled-level-set/gcls-level-set-article/figures/make_result_figures.py#L11-L17)).

## What it is

The layout is `docs/<theme>/<slug>-article/data/archive/<stamp>/`:

| path | content |
|---|---|
| `README.md` | what each subfolder holds, the code version of its runs, where the raw output lives, and the commands that regenerate it |
| `MANIFEST.csv` | the columns `file`, `rows`, `bytes`, `sha256` for every other file of the folder |
| one subfolder per source of runs | the first archive has `gate/`, `prefix/` and `laptop/` |

The subfolders of the first archive ([archive README](https://github.com/leia-openfoam/leia/blob/d1e3414/docs/gradient-controlled-level-set/gcls-level-set-article/data/archive/shared-method-config-2026-09-01-192-g1150e68/README.md#L13-L17)):

| folder | content | code version of the runs (`libleiaCore` stamp) | raw output |
|---|---|---|---|
| `gate/` | the fixed 2D method gate: per candidate the summary, orders, comparison and seam CSVs, `verdict.txt`, `candidate.json`, `exact1D.csv`; `cases.csv` with arm, N, ranks, state, steps and stamp of every case; reduced time histories per arm, about 300 rows per case | `...-192-g1150e68` | Lichtenberg, `studies/methodGate2D_*`, orchestrator 55048916 |
| `prefix/` | the same gate before the two parallel corrections; the 0.1 s translating runs | `...-173-g79b5a92` | Lichtenberg, the renamed pre-fix studies |
| `laptop/` | the translating runs and histories, the serial-against-np-4 check, the face-density check, the Eulerian mass-flux runs | per run; libraries `...-183-g935fd4e-dirty` with solver binaries built from b1798c3 | `runs/gcls-laptop-20260927` (git-ignored), with a copy on Lichtenberg |

The procedure ([archive README](https://github.com/leia-openfoam/leia/blob/d1e3414/docs/gradient-controlled-level-set/gcls-level-set-article/data/archive/shared-method-config-2026-09-01-192-g1150e68/README.md#L19-L34)):

1. On Lichtenberg, run `make_archive.py gate` and `make_archive.py prefix` over the studies.
2. On the laptop, run `make_archive.py laptop` over the preserved runs.
3. Run `make_archive.py manifest` to write `MANIFEST.csv`.
4. Run `make_result_figures.py --archive <archive> --figures data/figures --tables data/tables`. It writes the figures and the tables, then calls `make_gate_tables.py` on `<archive>/gate/summaries`.

What the scripts do:

- `make_archive.py` uses only the Python standard library, so it runs on the laptop and on the cluster login node ([L1-L17](https://github.com/leia-openfoam/leia/blob/d1e3414/docs/gradient-controlled-level-set/gcls-level-set-article/figures/make_archive.py#L1-L17)).
- It reads the state of each case with the log classifier, and the `libleiaCore` stamp from the case's `leia.version` ([L57-L65](https://github.com/leia-openfoam/leia/blob/d1e3414/docs/gradient-controlled-level-set/gcls-level-set-article/figures/make_archive.py#L57-L65), [L86-L93](https://github.com/leia-openfoam/leia/blob/d1e3414/docs/gradient-controlled-level-set/gcls-level-set-article/figures/make_archive.py#L86-L93)).
- It drops a row with a missing column, because a run that stopped on a floating-point exception can leave its last line incomplete ([L40-L44](https://github.com/leia-openfoam/leia/blob/d1e3414/docs/gradient-controlled-level-set/gcls-level-set-article/figures/make_archive.py#L40-L44)).
- It keeps about 300 rows of each time history, plus the last row ([L47-L54](https://github.com/leia-openfoam/leia/blob/d1e3414/docs/gradient-controlled-level-set/gcls-level-set-article/figures/make_archive.py#L47-L54)).
- The manifest holds the SHA-256 and the byte count of every file except `MANIFEST.csv`, and the row count of every CSV ([L347-L359](https://github.com/leia-openfoam/leia/blob/d1e3414/docs/gradient-controlled-level-set/gcls-level-set-article/figures/make_archive.py#L347-L359)).
- `make_result_figures.py` reads only the archive and the gate and candidate definitions ([L1-L10](https://github.com/leia-openfoam/leia/blob/d1e3414/docs/gradient-controlled-level-set/gcls-level-set-article/figures/make_result_figures.py#L1-L10)). It writes five PDF figures and eight LaTeX tables ([L367-L392](https://github.com/leia-openfoam/leia/blob/d1e3414/docs/gradient-controlled-level-set/gcls-level-set-article/figures/make_result_figures.py#L367-L392)).
- The figures and tables of four findings go to the data folder of the SL article, whatever `--figures` and `--tables` say. The findings are the seam check, the Eulerian mass-flux port, the translating droplet at long times and the oscillating drift ([L11-L17](https://github.com/leia-openfoam/leia/blob/d1e3414/docs/gradient-controlled-level-set/gcls-level-set-article/figures/make_result_figures.py#L11-L17), [L33-L36](https://github.com/leia-openfoam/leia/blob/d1e3414/docs/gradient-controlled-level-set/gcls-level-set-article/figures/make_result_figures.py#L33-L36)).

`.gitignore` exempts `docs/**/data/archive/**/*.csv` and `docs/**/data/figures/*.pdf` from its general patterns, because both are curated results ([`.gitignore`](https://github.com/leia-openfoam/leia/blob/d1e3414/.gitignore#L118-L121)). Three documents read the same folder. They are the appendix of the pre-print ([`gclsLevelSet.tex`](https://github.com/leia-openfoam/leia/blob/d1e3414/docs/gradient-controlled-level-set/gcls-level-set-article/gclsLevelSet.tex#L916-L942), `app:data`; [PDF](https://leia-openfoam.github.io/leia/preprints/gclsLevelSet.pdf)), the code and data statement of the SL article ([`semiLagrangianLevelSet.tex`](https://github.com/leia-openfoam/leia/blob/d1e3414/docs/semi-lagrangian-level-set/sl-level-set-article/semiLagrangianLevelSet.tex#L2803-L2813)), and the technical report ([`gclsTechnicalReport.tex`](https://github.com/leia-openfoam/leia/blob/d1e3414/docs/gradient-controlled-level-set/gcls-technical-report/gclsTechnicalReport.tex#L3-L7)).

## Why it matters

- A number in a pre-print can be defended only if a committed script regenerates it from committed configs ([CLAUDE.md](https://github.com/leia-openfoam/leia/blob/d1e3414/CLAUDE.md#L809-L811)). The per-version folder adds two facts to each number. The stamp gives the code version that produced it, and the digests show that the data did not change.
- The raw output stays outside git: the laptop runs alone are 1.5 GB in 539 files ([STATUS 11.16](https://github.com/leia-openfoam/leia/blob/d1e3414/STATUS.md#L4056-L4058)). The archive is the curated, versioned part of it.
- The archive keeps the pre-fix record next to the fixed gate, so the pre-print can show what the two parallel corrections changed ([[concepts/coupled-face-density-defect]]). `make_archive.py` reads the pre-fix studies under the dated names that the preservation step gave them ([L97-L104](https://github.com/leia-openfoam/leia/blob/d1e3414/docs/gradient-controlled-level-set/gcls-level-set-article/figures/make_archive.py#L97-L104), [CLAUDE.md](https://github.com/leia-openfoam/leia/blob/d1e3414/CLAUDE.md#L807-L808)).
- "Do not edit a curated table by hand" is the rule of the theme ([theme README](https://github.com/leia-openfoam/leia/blob/d1e3414/docs/gradient-controlled-level-set/README.md#L71-L72)).

## Decisions

- 2026-09-27: every number of a pre-print comes from one archive folder per software version. A new version gets a new folder, and an older folder is never overwritten ([STATUS 11.16](https://github.com/leia-openfoam/leia/blob/d1e3414/STATUS.md#L4050-L4056)).
- 2026-09-28: the four findings on the semi-Lagrangian baseline move to the SL article, and `make_result_figures.py` writes them into its data folders ([d1e3414](https://github.com/leia-openfoam/leia/commit/d1e3414), [theme README](https://github.com/leia-openfoam/leia/blob/d1e3414/docs/gradient-controlled-level-set/README.md#L74-L79)).

## Open questions

1. `make_archive.py` does not refuse an existing output folder. It creates the folder with `exist_ok=True` and writes its files again ([L68-L74](https://github.com/leia-openfoam/leia/blob/d1e3414/docs/gradient-controlled-level-set/gcls-level-set-article/figures/make_archive.py#L68-L74), [L108](https://github.com/leia-openfoam/leia/blob/d1e3414/docs/gradient-controlled-level-set/gcls-level-set-article/figures/make_archive.py#L108); DERIVED). The rule "an older folder is never overwritten" is therefore a convention that the script does not enforce.
2. At d1e3414 only the gradient-control pre-print has an archive. The curated tables of the other pre-prints have no per-version folder and no digests (git tree, 2026-09-29). No record decides whether the other pre-prints get one.
